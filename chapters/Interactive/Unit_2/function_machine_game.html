Unit 2 - Guess the Function Rule Game

In this game, you will interact with a function machine that takes an input number and produces an output. Your job is to study the input output pairs, look for patterns, and guess the rule the machine is using. There may be more than one rule that seems possible at first, so try different inputs to test your ideas. When you think you know the rule, lock it in and see if the machine agrees.

To learn more about the basics of functions, see 2.5 - Inputs and Outputs of Functions
