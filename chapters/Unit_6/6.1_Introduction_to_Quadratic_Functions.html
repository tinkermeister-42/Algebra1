6.1 - Introduction to Quadratics

Up to now, we have learned a lot about functions that model situations with straight-line behavior. Linear functions are useful in many real-world situations, but plenty of things do not move in straight lines. One example is the path of a thrown ball.

When you throw a ball, it rises, slows down, reaches a highest point, and then falls. If you traced the path it makes in the air, the curve would look like a smooth U shape.

How could we model something like this?

In this lesson, we will uncover a new type of function that can model curved paths like the one above. We call these functions quadratics.

6.1.1 - Identifying Quadratic Functions

In Unit 5 you learned that the degree of a polynomial tells us how the expression behaves. Linear functions have degree \(1\), which means their graphs can only move in one direction at a time. They never bend, so the result is always a straight line.

Quadratic functions raise the degree to \(2\), and that single change gives the graph the ability to curve once. This allows them to model situations that bend instead of moving in a straight path.

So how do you recognize a quadratic function?

There are a few good clues to look for, depending on whether you see an equation, a table, or a graph. Let’s start with equations.

From an Equation

When you look at an equation, the fastest way to recognize a quadratic is to check the highest power of x. If the highest power is \(2\), the function is quadratic.

Here are a few examples.

Example 1:

Is the function \(f(x) = 3x^2 - 4x + 1\) quadratic?

The highest power is \(2\).

So \(f(x)\) is a quadratic function.

Example 2:

Is \(g(x) = 5x - 9\) quadratic?

The highest power is \(1\). There is no \(x^2\) term.

So \(g(x)\) is not quadratic. It is linear.

Example 3:

Is \(h(x) = 7x^3 + 2\) quadratic?

The highest power is \(3\), which means the function curves more than once.

So \(h(x)\) is not quadratic. It is cubic.

Which of the following are quadratic functions?

  1. \(p(x) = 4x^2 + 6\)
  2. \(q(x) = 10 - x\)
  3. \(r(x) = x^2 - x^3\)
  4. \(s(x) = -3x^2 + 7x - 1\)
  5. \(g(x) = 4\)
  1. quadratic (degree 2)
  2. linear (degree 1)
  3. cubic (degree 3)
  4. quadratic (degree 2)
  5. constant (degree 0)

6.1.2 - Features of Quadratic Functions

Quadratics share three major features that help us understand their shape.

Opening direction

The coefficient in front of \(x^2\) tells which way the parabola opens.

  • Positive coefficient → opens upward
  • Negative coefficient → opens downward

Vertex

The vertex is the single turning point of the graph.

  • If the parabola opens upward, the vertex is a minimum.
  • If the parabola opens downward, the vertex is a maximum.

Symmetry

Every parabola has a vertical line that splits it into two matching halves. This will be important later when we study how to find the vertex.

6.1.3 - Domain and Range of Quadratics

This is the first time domain and range appear, so here is a simple introduction.

  • The domain is all the x values a function can take.
  • The range is all the y values the function can produce.

For quadratics:

  • The domain is all real numbers because you can plug in any x value.
  • The range depends on the vertex.

If a parabola opens upward, the lowest y value is at the vertex and everything else is above it. If it opens downward, the highest y value is at the vertex and everything else is below it.
