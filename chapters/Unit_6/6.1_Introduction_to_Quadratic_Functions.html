6.1 - Introduction to Quadratics

Up to now, we have learned a lot about functions that model situations with straight-line behavior. Linear functions are useful in many real-world situations, but many things do not move in straight lines. One example is the path of a thrown ball.

When you throw a ball, it rises, slows down, reaches a highest point, and then falls. If you traced the path it makes in the air, the curve looks like a smooth U shape.

How could we model something like this?

In this lesson, we will learn a new type of function that can model curved paths like the one above. We call these functions quadratics.

domain, function, maximum, minimum, parabola, quadratic function, range, vertex

6.1.1 - Identifying Quadratic Functions

In Unit 5 you learned that the degree of a polynomial tells us how the expression behaves. Linear functions have degree \(1\), which means their graphs can only move in one direction at a time. They never bend, so the result is always a straight line.

Quadratic functions raise the degree to \(2\), and that single change gives the graph the ability to curve once. This allows them to model situations that bend instead of moving in a straight path.

So how do you recognize a quadratic function?

There are a few ways to tell, depending on whether you see an equation, a table, or a graph. Let’s start with equations.

From an Equation

When you look at an equation, the fastest way to recognize a quadratic is to check the highest power of \(x\).
If the highest power is \(2\), the function is quadratic.

Here are a few examples.

Example 1:

Is the function \(f(x) = 3x^2 - 4x + 1\) quadratic?

The highest power is \(2\).

So \(f(x)\) is a quadratic function.

Example 2:

Is \(g(x) = 5x - 9\) quadratic?

The highest power is \(1\).
There is no \(x^2\) term.

So \(g(x)\) is not quadratic. It is linear.

Example 3:

Is \(h(x) = 7x^3 + 2\) quadratic?

The highest power is \(3\).

So \(h(x)\) is not quadratic. It is cubic.

Which of the following are quadratic functions?

  1. \(p(x) = 4x^2 + 6\)
  2. \(q(x) = 10 - x\)
  3. \(r(x) = x^2 - x^3\)
  4. \(s(x) = -3x^2 + 7x - 1\)
  5. \(t(x) = 4\)
  1. quadratic (degree 2)
  2. linear (degree 1)
  3. cubic (degree 3)
  4. quadratic (degree 2)
  5. constant (degree 0)

From a Graph

Now let’s look at how to identify a quadratic from its graph.

Quadratic functions create a smooth U-shaped curve called a parabola. A parabola has exactly one turning point. Both sides match if you imagine folding it in half.

The following example shows three different parabolas.

Example 4: Three Parabolas

Parabolas show up in more places than you might think. The curve of a quadratic function is the exact shape used in satellite dishes, car headlights, telescopes, and huge radio antennas.

Why that shape?

A parabolic reflector takes incoming light or sound and directs it to one precise spot, making it perfect for gathering signals or projecting powerful beams.

It’s one of the ways a simple algebraic curve becomes a tool engineers rely on every day.

6.1.2 - Features of Quadratic Functions

Every quadratic function creates a parabola. All parabolas have three main features.

  • Opening direction
  • Vertex
  • Axis of symmetry

Let’s take a look at each of these.

Opening Direction

A parabola can open upward, or it can open downward. The opening direction comes from the coefficient of the \(x^2\) term.

  • Positive coefficient → opens upward
  • Negative coefficient → opens downward

Example 5: Opens upward

The quadratic function \(f(x) = 2x^2 + 3x - 5\) has a positive coefficient on the \(x^2\) term and so it opens upward.

Example 6: Opens downward

The quadratic function \(f(x) = -0.5x^2 + 4\) has a negative \(x^2\) term and so it opens downward.

It will open upward because the coefficient on the \(x^2\) term is positive.

Vertex

The vertex is the single turning point of the graph.

  • If the parabola opens upward, the vertex is a minimum.
  • If the parabola opens downward, the vertex is a maximum.

Example 7: A maximum vertex

The function \(f(x) = -x^2 + 4x + 7\) has a vertex at \((2, 11)\). The coefficient on the \(x^2\) term is negative so the parabola opens downward and its vertex is a maximum.

Example 8: A minimum vertex

The function \(f(x) = 0.5x^2 -3x + 2.5\) has a positive coefficient on the \(x^2\) term and so the parabola opens upward and its vertex is a minimum.

Axis of Symmetry

Every parabola has a vertical line, passing through the vertex, that splits it into two matching halves. This vertical line is called the axis of symmetry.

The axis of symmetry is always \(x = h\), where \(h\) is the \(x\)-value of the vertex.

Example 9: The axis of symmetry of a parabola

The function \(f(x) = \tfrac{1}{4}(x + 2)^2 - 4\) has vertex \((-2, -4)\) and axis of symmetry \(x = -2\).

Note: we don’t need the graph to find the axis of symmetry if we know the vertex. The axis of symmetry is always a vertical line through the vertex.

Using the graph for the equation \(y = 2x^2 - 4x\) find its

  • opening direction
  • vertex
  • axis of symmetry
  • Opens upward
  • Vertex is \((1, -2)\)
  • Axis of symmetry is \(x = 1\)

6.1.3 - Domain and Range of Quadratics

As is true for linear functions, a parabola goes on forever in both directions along the \(x\)-axis. So the domain (all things \(x\) can be) is all real numbers, written \((-\infty, \infty)\).

Unlike linear functions, a quadratic function does not take all possible \(y\) values. Recall that when a parabola opens upward, its vertex is a minimum. When a parabola opens downward, its vertex is a maximum.

The set of possible \(y\) values is called the range. For any quadratic function with vertex \((h, k)\), its range is

  • \([k, \infty)\) if it opens upward
  • \((-\infty, k]\) if it opens downward

Example 10: Domain and range of a parabola

Find the domain and range of \(y = 0.5(x - 1)^2 - 1\) from its graph.

As with any parabola, the domain is all real numbers.

The vertex is at \((1, -1)\) and so the range is \([-1, \infty)\).

Example 11: Range of a parabola that opens downward

Find the range of the parabola with equation \(y = -3x^2 - 12x - 10\) from its graph.

The vertex is \((-2, 2)\) and so the range is \((-\infty, 2]\).

Using its graph, describe the following features for \(y = 2x^2 - 16x + 23\).

  • opening direction
  • vertex
  • axis of symmetry
  • domain
  • range
  • Opens upward
  • Vertex is \((4, -9)\)
  • Axis of symmetry is \(x = 4\)
  • Domain is all real numbers
  • Range is \([-9, \infty)\)
