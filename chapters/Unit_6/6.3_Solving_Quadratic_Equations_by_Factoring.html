6.3 - Solving Quadratic Equations by Factoring

In the last two lessons, we learned how to graph quadratic functions and describe the shapes of their parabolas. We now know how they open, where their vertices are, and how to find key features on the graph.

But quadratics are not just interesting curves. They also show up in equations we need to solve, like

\[ x^2 + 2x = 8. \]

It is natural to ask how we would solve an equation like this.

In this lesson, we will see that we already have all of the tools we need.

quadratic equation, real solution, root, x-intercept, zero product property

6.3.1 - Finding the x-intercepts of a quadratic function

In Unit 4, we learned how to find the x-intercepts of linear functions. A quadratic works the same way. We look for the points where the graph touches or crosses the x-axis.

But unlike lines, a parabola can have two, one, or zero x-intercepts.

  • The parabola on the left touches the x-axis once.
  • The parabola in the middle crosses the x-axis twice.
  • The parabola on the right never touches the x-axis.

These values of \(x\) are the roots or zeros of the function. They occur exactly when the output of the function is zero.

This idea is the key to why we solve equations by setting them equal to zero.

Example 1: Finding x-intercepts by graphing

Consider the function

\[ f(x) = x^2 + 2x - 15. \]

Before graphing, we can use what we already know.

  • The vertex is at \((-1, -16)\), which is below the x-axis.
  • The parabola opens upward.

Since the lowest point is below the x-axis and the graph opens upward, the parabola must cross the x-axis twice.

Now look at the graph.

The x-intercepts are the points where the graph crosses the x-axis, meaning where the output is \(0\).

From the graph, we can see that:

  • one crossing occurs near \(x = -5\)
  • the other crossing occurs near \(x = 3\)

So the x-intercepts are approximately \((-5, 0)\) and \((3, 0)\).

Because graphing is not perfectly precise, we usually do not rely on this method to find exact solutions. Instead, we use algebra to find the exact x-values.

We will now solve this same quadratic algebraically and confirm these results exactly.

6.3.2 - Solving quadratic equations by factoring

To find the exact x-intercepts, we need an algebraic method. This is where the quadratic equation comes in.

\[ ax^2 + bx + c = 0 \]

But why do we set the equation equal to zero?

X-intercepts occur when the output is zero. So if we want to find where the graph hits the x-axis, we must solve the equation that results from setting the function equal to zero.

This connects directly to Unit 5. Once a quadratic is written as an expression equal to zero, we can factor it and use the zero product property.

If a product equals zero, then at least one factor must be zero. Each factor gives a possible solution.

Example 2: Solving a quadratic equation by factoring

We already graphed the function

\[ f(x) = x^2 + 2x - 15. \]

To find its x-intercepts algebraically, we set the output equal to zero.

\[ x^2 + 2x - 15 = 0 \]

Now we factor the quadratic.

\[ (x + 5)(x - 3) = 0 \]

Each factor gives a possible solution.

  • \(x + 5 = 0 \Rightarrow x = -5\)
  • \(x - 3 = 0 \Rightarrow x = 3\)

These solutions match the x-intercepts we saw on the graph.

Example 3: A quadratic not in standard form

Solve

\[ 2x^2 = 3x + 4. \]

Before factoring, we move all terms to one side so the equation equals zero.

\[ 2x^2 - 3x - 4 = 0 \]

Now we factor.

\[ (2x + 1)(x - 4) = 0 \]

Setting each factor equal to zero gives

  • \(x = -\tfrac{1}{2}\)
  • \(x = 4\)

Example 4: Taking out a GCF

Solve

\[ 8x^2 + 60x + 72 = 0. \]

All terms share a common factor of \(4\), so we factor it out first.

\[ 4(2x^2 + 15x + 18) = 0 \]

Dividing both sides by \(4\) keeps the solutions the same and makes the equation easier to factor.

\[ (x + 6)(2x + 3) = 0 \]

The solutions are

  • \(x = -6\)
  • \(x = -\tfrac{3}{2}\)

Example 5: A higher-degree equation

The same strategy works whenever the entire expression can be factored.

Solve

\[ 3x^3 = 9x + 6x^2. \]

First, rewrite the equation so it equals zero.

\[ 3x^3 - 6x^2 - 9x = 0 \]

Now factor step by step.

\[ 3x(x^2 - 2x - 3) = 0 \]

\[ 3x(x + 1)(x - 3) = 0 \]

Each factor gives a solution.

  • \(x = 0\)
  • \(x = -1\)
  • \(x = 3\)

\[ \begin{aligned} 3x^2 - 7x &= 6 \\ 3x^2 - 7x - 6 &= 0 \\ (x - 3)(3x + 2) &= 0 \end{aligned} \]

The solutions are

  • \(x = 3\)
  • \(x = -\tfrac{2}{3}\)

6.3.3 - How many solutions can a quadratic equation have?

A quadratic function can have two, one, or zero x-intercepts. Because solving a quadratic equation is the same as finding its x-intercepts, the equation itself can have the same possibilities.

Example 6: Two solutions

Solve

\[ x^2 - 5x + 6 = 0. \]

Factoring gives

\[ (x - 2)(x - 3) = 0. \]

The solutions are \(x = 2\) and \(x = 3\). Because there are two different solutions, the graph crosses the x-axis twice.

Example 7: One solution

Solve

\[ x^2 - 6x + 9 = 0. \]

This quadratic factors as a perfect square.

\[ (x - 3)^2 = 0 \]

Both factors give the same solution, \(x = 3\). On the graph, the parabola touches the x-axis at exactly one point.

Example 8: No real solutions

Solve

\[ x^2 + 4x + 7 = 0. \]

There are no two real numbers that multiply to \(7\) and add to \(4\), so this quadratic does not factor over the real numbers.

That means there is no real value of \(x\) that makes the equation true. On the graph, the parabola never touches the x-axis.

Putting it all together

  • Two different linear factors lead to two solutions.
  • A repeated factor leads to one solution.
  • No real factors lead to no real solutions.

These algebraic results match exactly what we see on the graph.
