6.4 - Completing the Square

In the last lesson, we solved quadratic equations by factoring. When a quadratic factors nicely, this method works well.

But not all quadratic equations factor using integers.

For example,

\[ x^2 + 6x + 5 = 0 \]

factors easily, while

\[ x^2 + 6x + 2 = 0 \]

does not.

Both parabolas cross the \(x\)-axis twice, so both equations have two solutions. We can find the solutions to the first equation by factoring:

\[ \begin{aligned} x^2 + 6x + 5 &= 0 \\ (x + 5)(x + 1) &= 0 \end{aligned} \]

This gives the solutions \(x = -5\) and \(x = -1\).

But factoring does not work for the second equation. We need a method that works every time, even when factoring fails.

In this lesson, we will learn a method called completing the square. This method always works for quadratic equations. What’s more, it leads directly to one of the most important formulas in algebra: the quadratic formula.

completing the square, quadratic equation, perfect square, square root

6.4.1 - Turning \(x^2 + bx\) into a Perfect Square

In Unit 5, we learned how to recognize and factor perfect square trinomials.

Those trinomials always come from squaring a binomial:

\[ (x + a)^2 = x^2 + 2ax + a^2 \]

Completing the square is the reverse idea.

Instead of starting with a square and expanding it, we start with part of the expression and figure out what is missing to make a square.

One way to see this clearly is to use an area model, just like we did when factoring.

Example 1: Completing the Square with an Area Model

Let’s start with the expression:

\[ x^2 + 10x \]

Our goal is to turn this into a perfect square trinomial, which comes from squaring a binomial.

That means there is only one binomial factor, used twice.

So the two terms on the diagonal of the area model must be the same.

To make that happen, the middle term must be split evenly:

\[ 10x = 5x + 5x \]

\(x\) \(5\)
\(x\) \(x^2\) \(5x\)
\(5\) \(5x\) ?

Only one piece is missing. To complete the square, that piece must be:

\[ 5 \times 5 = 25 \]

\(x\) \(5\)
\(x\) \(x^2\) \(5x\)
\(5\) \(5x\) \(25\)

Now we have a perfect square, but it is not the original expression. We added \(25\) to create the square.

To keep the value the same, we must subtract that \(25\) back out:

\[ x^2 + 10x = (x + 5)^2 - 25 \]

Example 2: A negative middle term

Rewrite:

\[ x^2 - 6x \]

Split the middle term:

\[ -6x = -3x - 3x \]

\(x\) \(-3\)
\(x\) \(x^2\) \(-3x\)
\(-3\) \(-3x\) \(9\)

So,

\[ x^2 - 6x = (x - 3)^2 - 9 \]

Example 3: A fractional middle term

Instead of drawing the full area model, we can apply the same idea algebraically.

Rewrite:

\[ x^2 + 3x \]

Half of \(3\) is \(\tfrac{3}{2}\):

\[ x^2 + 3x = (x + \tfrac{3}{2})^2 - \tfrac{9}{4} \]

\[ x^2 + 8x = (x + 4)^2 - 16 \]

6.4.2 - Completing the Square When a ≠ 1

Completing the square works best when the coefficient of \(x^2\) is \(1\). If it is not, we fix that first.

Example 4: Completing the square when a ≠ 1

Rewrite:

\[ 3x^2 + 12x \]

First, factor out the leading coefficient:

\[ 3(x^2 + 4x) \]

Complete the square inside the parentheses:

\[ x^2 + 4x = (x + 2)^2 - 4 \]

Substitute back:

\[ 3((x + 2)^2 - 4) \]

Simplify:

\[ 3(x + 2)^2 - 12 \]

Example 5: Completing the square in an equation

Rewrite by completing the square:

\[ 2x^2 + 8x + 3 = 0 \]

First, factor out the leading coefficient and isolate the \(x\) terms:

\[ \begin{aligned} 2(x^2 + 4x) + 3 &= 0 \\ 2(x^2 + 4x) &= -3 \\ x^2 + 4x &= -\tfrac{3}{2} \end{aligned} \]

Now complete the square for \(x^2 + 4x\) using an area model.

Split the middle term evenly:

\[ 4x = 2x + 2x \]

\(x\) \(2\)
\(x\) \(x^2\) \(2x\)
\(2\) \(2x\) ?

The missing corner must be:

\[ 2 \times 2 = 4 \]

So we add \(4\) to both sides of the equation:

\[ x^2 + 4x + 4 = -\tfrac{3}{2} + 4 \]

Now the left side is a perfect square:

\[ (x + 2)^2 = \tfrac{5}{2} \]

6.4.3 - Solving by Taking Square Roots

The reason we complete the square is not just to rewrite expressions. We do it because it puts a quadratic equation into a form that is easy to solve.

Once an equation is written as

\[ (x - h)^2 = k \]

we can solve it by taking square roots of both sides.

Example 6: Solving by taking square roots

Solve:

\[ (x + 2)^2 = \tfrac{5}{2} \]

Take the square root of both sides:

\[ \begin{aligned} x + 2 &= \pm \sqrt{\tfrac{5}{2}} \\ x &= -2 \pm \sqrt{\tfrac{5}{2}} \end{aligned} \]

When we undo a square, we must include both possibilities.

For example,

\[ 5^2 = 25 \quad \text{and} \quad (-5)^2 = 25 \]

Both values square to the same result, so both must be included when taking a square root.

Example 7: Solving by completing the square

Solve:

\[ x^2 + 4x - 1 = 0 \]

First, isolate the \(x\) terms:

\[ x^2 + 4x = 1 \]

Now complete the square for \(x^2 + 4x\) using an area model.

Split the middle term evenly:

\[ 4x = 2x + 2x \]

\(x\) \(2\)
\(x\) \(x^2\) \(2x\)
\(2\) \(2x\) ?

The missing corner must be:

\[ 2 \times 2 = 4 \]

Add \(4\) to both sides of the equation:

\[ x^2 + 4x + 4 = 1 + 4 \]

Now the left side is a perfect square:

\[ (x + 2)^2 = 5 \]

Take the square root of both sides:

\[ \begin{aligned} x + 2 &= \pm \sqrt{5} \\ x &= -2 \pm \sqrt{5} \end{aligned} \]

Example 8: No real solutions

Solve:

\[ (x + 1)^2 = -6 \]

We would normally solve this by taking the square root of both sides:

\[ x + 1 = \pm \sqrt{-6} \]

But \(\sqrt{-6}\) is not a real number.

A square represents a real number multiplied by itself, and any real number squared is zero or positive.

Since \(-6\) is negative, there is no real number whose square equals \(-6\).

So this equation has no real solutions.

Solve by completing the square:

\[ x^2 - 10x + 16 = 0 \]

Move the constant:

\[ x^2 - 10x = -16 \]

Split the middle term:

\[ -10x = -5x - 5x \]

\(x\) \(-5\)
\(x\) \(x^2\) \(-5x\)
\(-5\) \(-5x\) ?

Fill the missing corner:

\[ (-5)(-5) = 25 \]

Add \(25\) to both sides:

\[ x^2 - 10x + 25 = -16 + 25 \]

Rewrite and solve:

\[ \begin{aligned} (x - 5)^2 &= 9 \\ x - 5 &= \pm 3 \\ x &= 8 \quad \text{or} \quad x = 2 \end{aligned} \]
