3.5 Equations With No or Infinite Solutions

So far, every equation we solved had exactly one solution. After simplifying and moving terms, we always ended with something like

\[ x=5 \]

which tells us the one value that makes the equation true.

But equations don’t always behave that way. Sometimes:

  • there is no value that makes the equation true, or
  • every value works.

These are called special cases. In this lesson, we’ll see what they look like and how to spot them.

Note

all real numbers, linear equation, no solution, real numbers

3.5.1 – Equations With No Solution

In the last lesson, when we moved variables to one side, we always ended up with a single answer like \(x = 4\). But sometimes, something different happens. After simplifying, the variables cancel out and we’re left with a statement that is false.

When this happens, the equation has no solution — there is no value that will make both sides equal.

Example 1:

Solve \(3x + 5 = 3x - 2\).

\[ \begin{align*} 3x + 5 &= 3x - 2 \\ 3x + 5 \textcolor{red}{- 3x} &= 3x - 2 \textcolor{red}{- 3x} \\ 5 &= -2 \tag*{\class{stepnote}{\textcolor{red}{false statement}}} \end{align*} \]

Since \(5 = -2\) is not true, there is no solution.

Example 2:

Solve \(2(x + 4) = 2x + 7\).

\[ \begin{align*} 2(x + 4) &= 2x + 7 \\ 2x + 8 &= 2x + 7 \\ 2x + 8 \textcolor{red}{- 2x} &= 2x + 7 \textcolor{red}{- 2x} \\ 8 &= 7 \tag*{\class{stepnote}{\textcolor{red}{false statement}}} \end{align*} \]

This is also false, so there is no solution.

If you solve an equation and end up with two different numbers on either side of the equals sign, there is no solution.

3.5.2 – Equations With Infinitely Many Solutions

Sometimes when you solve, the variables cancel out and you’re left with a statement that is always true. In that case, every number works, so the equation has infinitely many solutions.

Example 1:

Solve \(4(x + 2) = 2(2x + 4)\).

\[ \begin{align*} 4(x + 2) &= 2(2x + 4) \\ 4x + 8 &= 4x + 8 \\ 4x + 8 \textcolor{red}{- 4x} &= 4x + 8 \textcolor{red}{- 4x} \\ 8 &= 8 \tag*{\class{stepnote}{\textcolor{green}{true statement}}} \end{align*} \]

Because \(8 = 8\) is always true, any value of \(x\) will make the original equation work.

Example 2:

Solve \(5y - 3 + 2y = 7y - 3\).

\[ \begin{align*} 5y - 3 + 2y &= 7y - 3 \\ 7y - 3 &= 7y - 3 \\ 7y - 3 \textcolor{red}{- 7y} &= 7y - 3 \textcolor{red}{- 7y} \\ -3 &= -3 \tag*{\class{stepnote}{\textcolor{green}{true statement}}} \end{align*} \]

Again, the result is always true. The solution is all real numbers.

If you solve an equation and get the same thing on each side of the equal sign, the problem has infinitely many solutions. All real numbers will work.

3.5.3 – Determining the Number of Solutions

There are some tricks for telling whether a linear equation will have one, no, or infinitely many solutions. You can often see it without actually solving the equation all the way!

Equations With One Solution If a linear equation has a variable term on one side and a different constant term on the other side, it will have one solution.

Example:

\[ 6x = 42 \]

There’s a variable term, \(6x\), on one side and a constant, \(42\), on the other. Solve to see:

\[ x = 7 \quad \text{(divide both sides by 6)} \]

So this equation has one solution: \(x = 7\).

Equations With No Solution If both sides have the same variable term but different constants, the equation has no solution.

Example:

\[ 3x + 8 = 3x + 1 \]

The variable part \(3x\) matches on both sides, but the constants \(8\) and \(1\) don’t.

\[ 8 = 1 \quad \text{(after subtracting $3x$ from both sides)} \]

This is false, so the equation has no solution.

Equations With Infinitely Many Solutions If both sides have the same variable term and the same constant, the equation has infinitely many solutions.

Example:

\[ 7x + 9 = 7x + 9 \]

Both sides are identical.

\[ 9 = 9 \quad \text{(after subtracting $7x$ from both sides)} \]

This is always true, so every value of \(x\) works.

  • Different variable and constant terms left and right → One solution
  • Same variable, different constants → No solution
  • Same variable, same constants → Infinitely many solutions
  • \(\varnothing\) is often used in place of “no solution” to save space and
  • \(\mathbb{R}\) is used in place of “all real numbers” or infinitely many solutions
  1. \(5x + 2 = 3x + 10\)
  2. \(4y + 7 = 4y - 5\)
  3. \(6n + 9 = 9 + 6n\)
  1. one solution
  2. no solution (\(\varnothing\))
  3. infinitely many solutions (\(\mathbb{R}\))
