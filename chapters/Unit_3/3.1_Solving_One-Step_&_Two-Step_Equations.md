# 3.1 – Solving One- and Two-Step Equations {.unnumbered}

In Unit 2, we learned how to work with {{< glink equivalent expressions >}}. Sometimes we could check a number, {{< glink substitute >}} it into both expressions, and see that they matched. But, with some expressions, we noticed something important:

Some values worked.

Other values didn’t.

This brings us to **equations**. In this unit, we flip the process around: instead of testing random values to see if two expressions are equal, we will learn how to **find the values that make them equal**.

Those values are called the {{< glink solutions >}} of the equation.

In this lesson, we begin with the basic rules for solving equations:

- Keep both sides equal.

- Undo operations step by step until the variable is by itself.

Later lessons will build on these rules to solve more complicated equations.

## 3.1.1 – Equations as Balances 

An equation is like a scale: both sides must stay equal.

**Example – One-Step Equation (Addition/Subtraction)**
Solve $x + 2 = 7$.

* **Balance:** apple + 2 weights = 7 weights. Remove 2 from both sides.
* **Tiles:** 1 $x$-tile + 2 units = 7 units. Take away 2 units from each side.
* **Symbols:**
  $x + 2 = 7$
  $x = 5$

👉 Always undo the constant first when it’s being added or subtracted.

---

## 3.1.2 – Multiplication and Division

If the variable is being multiplied or divided, we undo with the opposite operation.

**Example 1 – Multiplication**
Solve $4x = 20$.

* **Balance:** 4 apples = 20 weights. Divide both sides into 4 groups.
* **Symbols:**
  $4x = 20$
  $x = 5$

**Example 2 – Negative Variable**
Solve $-3x = 12$.

* Divide both sides by –3.
* $x = -4$

**Example 3 – Fraction Coefficient**
Solve $\tfrac{x}{5} = 3$.

* Multiply both sides by 5.
* $x = 15$

---

## 3.1.3 – Two-Step Equations

When the variable has more than one operation, we undo them in reverse order.

**Example 1 – Positive Variable**
Solve $2x + 3 = 11$.

* **Balance:** 2 apples + 3 = 11 weights. Remove 3 from both sides. Divide the 8 into 2 groups.
* **Symbols:**
  $2x + 3 = 11$
  $2x = 8$
  $x = 4$

---

**Example 2 – Negative Variable**
Solve $-5x + 7 = -8$.

* Subtract 7 from both sides: $-5x = -15$.
* Divide by –5: $x = 3$.

---

**Example 3 – Fraction Coefficient**
Solve $\tfrac{1}{2}x - 4 = 2$.

* Add 4 to both sides: $\tfrac{1}{2}x = 6$.
* Multiply both sides by 2: $x = 12$.

---

## 3.1.4 – Checking a Solution ✅

You can always check your work by plugging the answer back in.

**Example – Check**
Solve $3x - 5 = 16$.

* Add 5: $3x = 21$
* Divide by 3: $x = 7$
* Check: $3(7) - 5 = 21 - 5 = 16$.
