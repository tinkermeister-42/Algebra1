4.3 – The Equation of a Line

In the last lesson, you learned how to find and use the slope of a line. Now we’ll see how slope connects to a line’s equation — and how one special point called the intercept makes everything fit together.

linear equation, slope, y-intercept, x-intercept, slope-intercept form, function notation

🔥 Warm-Up

Think about what you already know:

  • What does slope tell us about a line?
  • If you have one point on a line, how could you use the slope to find another?

4.3.1 – Graphing a Line Using a Point and the Slope

A line’s slope is constant — it never changes no matter which points you use. That means if you know one point, you can find as many others as you want.

Example 1 – Graph from a Point and Slope

Graph the line with slope \(m = \tfrac{1}{3}\) passing through the point \((0, 1)\).

The slope means “up 1 for every 3 to the right.” Starting at \((0, 1)\), move right 3 and up 1 to reach \((3, 2)\).

4.3.2 – Discovering Intercepts

Every line crosses the axes somewhere. Those crossing points are special because they’re easy to find — and they tell us a lot about the line.

Let’s look at an example and see what happens.

Example 2 – Where Does It Cross?

Graph \(y = \tfrac{3}{4}x - 3\). Then find where it crosses each axis.

Let’s use \(x = 8\) and \(x = -4\).

\(x\) \(y\)
\(8\) \(3\)
\(-4\) \(-6\)

You can see two important points:

  • It crosses the y-axis at \((0, -3)\).
  • It crosses the x-axis around \((4, 0)\).

Those are called intercepts.

The x-intercept is where the line crosses the x-axis → it always looks like \((x, 0)\). The y-intercept is where the line crosses the y-axis → it always looks like \((0, y)\).

4.3.3 – Finding Intercepts Algebraically

You don’t always need a graph. Because we know what the coordinates look like, we can set one variable to 0 and solve for the other.

Example 3 – Find the Intercepts

Find the x- and y-intercepts of \(y = x - 5\).

x-intercept: set \(y = 0\)

\[ \begin{align*} 0 &= x - 5\\ x &= 5 \end{align*} \]

So the x-intercept is \((5, 0)\).

y-intercept: set \(x = 0\)

\[ y = 0 - 5 = -5 \]

So the y-intercept is \((0, -5)\).

x-intercept: \[ \begin{align*} 0 &= 2x + 1\\ x &= -\tfrac{1}{2} \end{align*} \]

\((- \tfrac{1}{2}, 0)\)

y-intercept: \[ y = 2(0) + 1 = 1 \]

\((0, 1)\)

To find intercepts:

  • set \(y=0\) → get the x-intercept
  • set \(x=0\) → get the y-intercept

4.3.4 – The Equation of a Line

Now we can tie everything together.

Every non-vertical line can be written as

\[ y = mx + b \]

where

  • \(m\) is the slope, and
  • \(b\) is the y-intercept (the point where the line crosses the y-axis).

This is the slope-intercept form of a line.

Example 4 – Graph from an Equation

Graph \(y = \tfrac{2}{3}x - 2\).

Start at the y-intercept \((0, -2)\). Then use the slope \(m = \tfrac{2}{3}\) → up 2, right 3.
