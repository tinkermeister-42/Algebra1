4.1 – Graphing Function Rules

So far, you’ve worked with rules that take an input, do something to it, and give an output. You’ve written equations, evaluated expressions, and created tables that show how numbers are connected.

In this lesson, we’ll take that same idea one step further. Instead of only listing input–output pairs, we’ll see them — each pair becomes a point you can plot. When those points come together, they reveal a picture of the rule itself.

It’s time to move from numbers to shapes — and start seeing how a function behaves.

4.1.1 – The Coordinate Plane

Up to now, we’ve worked with number lines — simple one-dimensional ways to show where a number belongs. But equations often have two variables, like \(x\) and \(y\). To show how they’re related, we need a way to display two numbers at once.

That’s where the coordinate plane comes in.

The coordinate plane is made by crossing two number lines:

  • The x-axis runs left and right.
  • The y-axis runs up and down. They meet at the origin (0, 0).

Every point on the plane has an ordered pair of numbers called its coordinates: \((x, y)\). The first number tells how far to move left or right, and the second tells how far to move up or down.

The axes divide the plane into four quadrants, labeled with Roman numerals I–IV, starting in the top-right and going counterclockwise.

When you plot a point, start at the origin:

  1. Move left or right for the x-coordinate.
  2. Then move up or down for the y-coordinate.
  3. Mark the spot.

Example:

Plot the points \((4, 2), (-6, 4), (-4, -8)\) and \((8, -4)\).

1. \((-4, 0)\) 2. \((-8, 8)\) 3. \((-2, -8)\) 4. \((0, 0)\)
5. \((0, 4)\) 6. \((6, 2)\) 7. \((7, -3)\) 8. \((4, 7)\)

1 : “G”, 2 : “B”, 3 : “C”, 4 : “E”, 5 : “H”, 6 : “A”, 7 : “D”, 8 : “F”

Now that we know how to plot points, let’s see how a rule — like an equation — can generate points that form a picture.

4.1.2 – Function Rules and Tables of Values

In Unit 2, we learned how to find the output of a function for a given input.
Each input/output pair forms a point we can plot.
By connecting those points, we can see what the function looks like.

Example 1

Let \(f(x) = 2x + 1\).

To graph \(f(x)\), we first make a table of values for several \(x\) inputs.
Let’s use \(x = 1, 2, 3,\) and \(4\).

\[ \begin{align*} f(\textcolor{red}{1}) &= 2(\textcolor{red}{1}) + 1 = 3 \\ f(\textcolor{red}{2}) &= 2(\textcolor{red}{2}) + 1 = 5 \\ f(\textcolor{red}{3}) &= 2(\textcolor{red}{3}) + 1 = 7 \\ f(\textcolor{red}{4}) &= 2(\textcolor{red}{4}) + 1 = 9 \end{align*} \]

\(x\) \(f(x)\)
1 3
2 5
3 7
4 9

Now plot each pair \((x, f(x))\) on a coordinate plane.

When we connect the points, they form a straight line — showing that \(f(x) = 2x + 1\) is a linear function.

When an equation has one variable, its answer is just one number. On a number line, that number is shown as a single point.

But when an equation has two variables, it doesn’t have just one answer — it has many! In fact, all of the (x, y) pairs that make the equation true line up to form a straight line. That’s why we graph the equation — the line shows all the solutions.

\(f(x)\) means the same thing as \(y\).
It’s just a different way to name the output of a function.
So the equation \(f(x) = 2x + 1\) could also be written as \(y = 2x + 1\).

Let’s look at another function that behaves a little differently.

Example 2:

Let \(h(x) = -\frac{2}{3}x - 3\).

Evaluate \(h(x)\) for \(x = -3, 0,\) and \(3\) and graph the result.

\(x\) \(h(x)\)
-3 -1
0 -3
3 -5

Yes! Each \(x\) value gives only one \(y\) value.
That’s what makes it a function — every input leads to exactly one output.

\(x\) \(g(x)\)
-1 \(-5\)
1 \(1\)
3 \(7\)

Not every function will make a straight line, but when it does, we can describe it with a rule like \(f(x) = mx + b\) (or \(y = mx + b\)).

For now, just notice that these kinds of rules always make points that line up perfectly.
