2.5 - Inputs and Outputs of Functions

So far in this unit, you’ve learned how to evaluate expressions by plugging in values for variables. You’ve also simplified expressions using distribution and by combining like terms.

Now picture a small mystery machine on a desk with a sign that says “Feed me.” On the machine is a big letter “f” and on the table are number cards. You slide a 5 into the top, and out comes 13. You try 7, and out comes 17. When you feed the same number again, you get the same result again. It seems the machine is following a steady rule.

What could the rule be? How could we name it so others know exactly what it does? Machines like this—where each input leads to one specific output—are called functions.

2.5.1 - What Is Function Notation?

Imagine our “mystery machine” from the introduction.

Did you figure out what rule the machine is following? With only two examples, we can’t be 100% sure, but from the examples we have (5 → 13, 7 → 17), one possible rule is: “double the input and then add 3”.

In algebra, we name the machine and write its rule using function notation.

\[ f(x) = 2x+3 \]

  • \(f\) is the name of the function (we also use \(g\), \(h\), etc.).
  • \(f(x)\) (read “f of x”) means \(x\) is the input variable.
  • \(2x + 3\) is the rule for the output. It tells what to do to \(x\).

Read \(f(x)\) as “\(f\) of \(x\).” It is a single name for the output when the input is \(x\). It does not mean to multiply \(f\) and \(x\).

It takes the input \(y\), doubles it, and subtracts 2.

Example: \(g(3) = 2(3)-2 = 4\)

2.5.2 - Is It a Function? (Using Tables)

A relation is any set of input-output pairs. A function is a special kind of relation: each input has exactly one output.

We can check this quickly with an input/output table.

How to check a table

  1. Scan the input column. If the same input appears with two different outputs, it is not a function.

  2. Repeated input is okay if the output is the same. If an input repeats but the output matches each time, it can still be a function.

  3. Outputs may repeat. Different inputs can share the same output. That’s allowed.

  4. Not enough information? A small table doesn’t prove something is a function for all inputs, but it can show when it is not a function.

Example 1: A function

Input Output
2 7
3 9
2 7
4 11

The input 2 shows up twice, but with the same output (7). This table is consistent with a function.

Example 2: Not a function

Input Output
1 4
1 5

The input 1 has two different outputs (4 and 5). Not a function.

It’s okay if different inputs give the same output. For example, two different temperatures could both “feel like” 75°F. That does not break the function rule.

2.5.3 - Evaluating Functions

Function notation is a handy way to describe expression evaluation.

Suppose we are asked to evaluate the expression \(2x + 3\) when \(x = 5\). We would do this:

\[ \begin{align*} 2(\textcolor{red}{5}) + 3 &= 10 + 3 \\ &= 13 \end{align*} \]

Functions let us ask the same question with less writing. Instead we can just say “Find \(f(5)\)”.

\[ \begin{align*} f(\textcolor{red}{5}) &= 2(\textcolor{red}{5}) + 3 \\ &= 10 + 3 \\ &= 13 \end{align*} \]

Example 3: Evaluating functions

Let \(g(x) = 3(x+4)\). Find \(g(2)\).

\[ \begin{align*} g(\textcolor{red}{2}) &= 3(\textcolor{red}{2}+4) \\ &= 3(6) \\ &= 18 \end{align*} \]

Example 4: Evaluating functions with negative numbers

Let \(h(x) = -2(3x-1)+7\). Find \(h(-2)\).

\[ \begin{align*} h(\textcolor{red}{-2}) &= -2(3(\textcolor{red}{-2})-1)+7 \\ &= -2(-6 - 1) + 7 \\ &= -2(-7)+7 \\ &= 21 \end{align*} \]

Programmers spend much of their time writing functions. A function has a name, takes inputs (also called parameters), and produces one output. The code behind any app you use often has hundreds, and sometimes thousands, of functions.

\(f(2) = 9 - 3(2) = 9 - 6 = 3\)

2.5.4 - Simplifying Function Rules

Sometimes a rule is easier to use after you simplify it.

Example 5: Simplifying before evaluation

\[ p(x) = 4(x-2) + 3x \]

First simplify:

\[ \begin{align*} p(x) &= 4x-8+3x \\ &= 7x-8 \end{align*} \]

Now evaluate at \(x=5\):

\[ \begin{align*} p(5) &= 7(5)-8 \\ &= 27 \end{align*} \]

A shorter rule makes evaluation quicker and reduces mistakes.

Whenever possible, simplify before substituting—then you only have to do it once, no matter what input you plug in.

\(q(x) = 5x+10\), so \(q(3)=25\).

2.5.5 - Function Evaluation in Real Life

Functions don’t just show up in math class—they model real situations. In science, functions describe how the world works. In everyday life, they help you predict costs or convert measurements. Below are two common examples.

Example 6: Cellphone data plan

A data plan charges a $50 flat fee per month plus $0.10 per Gb. How much will you pay if you use 80 Gb?

We can model the total cost with the function

\[ C(g) = 50 + 0.1g \]

where \(C\) is the total cost (dollars) and \(g\) is data used (Gb).

Substitute \(g=80\):

\[ \begin{align*} C(80) &= 50 + 0.1(80) \\ &= 50 + 8 \\ &= 58 \end{align*} \]

The total cost is $58.

Example 7: Temperature conversion (°C → °F)

To convert from Celsius to Fahrenheit, use

\[ F(C) = \frac{9}{5}C + 32 \]

Find 25°C in Fahrenheit.

\[ \begin{align*} F(25) &= \tfrac{9}{5}\cdot 25 + 32 \\ &= 45 + 32 \\ &= 77^\circ\mathrm{F} \end{align*} \]

25°C = 77°F

You are paid $12 per hour plus a $15 bonus. You can represent your pay using

\[ P(h) = 12h + 15 \]

where \(h\) is the number of hours worked and \(P\) is your total pay.

How much do you make if you work for 40 hours?

\(P(40) = 12(40) + 15 = 480 + 15 = 495\) You make $495.

Real-world applications:

  1. A taxi charges $4 plus $2 per mile. Write a function \(C(m)\) for the cost of a ride with \(m\) miles. How much is a 10-mile ride?

  2. A video game character earns 50 points per level plus a 100-point bonus. Write a function \(P(\ell)\) for total points after \(\ell\) levels. How many points after 6 levels?

  4. You earn $15 per hour mowing lawns. Write a function \(E(h)\). How much do you earn in 12 hours?

Mixed practice:

  4. Suppose \(f(x)=2x+3\). If the output is 23, what was the input?
