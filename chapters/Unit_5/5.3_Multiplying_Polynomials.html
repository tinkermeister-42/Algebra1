5.3 - Multiplying Polynomials

You already know how to multiply a single term by a polynomial, distribute and combine like terms. But once both polynomials have more than one term, things can get complicated in a hurry.

Take something like:

\[(x + 4)(x^2 - 3x + 2).\]

Every part of the first polynomial needs to connect with every part of the second. How many products does that make? And what’s the best way to organize all those pieces so nothing gets lost?

In this lesson, you’ll learn a method that keeps everything in order and works for any size polynomial. It gives you the structure you need now, and it sets up the skills we’ll use later when we start factoring.

area model, binomial, monomial, polynomial

🔥 Warm Up

  1. Rewrite \(342\) as the sum of its place-value parts.

  2. Expand: \(4x(3x^2 - 2x + 5)\).

  3. Predict: how many individual products will appear if you multiply \((x + 3)(x^2 - x + 5)\)?

5.3.1 - Multiplying Polynomials Using Distribution

You already know how to multiply a monomial times a polynomial by distributing. But what about when both polynomials have more than one term?

Let’s try the method you know and see what happens.

Example 1: Multiplying two binomials with distribution

Multiply \((2x + 3)(3x - 5)\) using only distribution.

Break the second polynomial into its parts and distribute the first polynomial over them:

\[ \begin{aligned} (2x + 3)(3x - 5) &= (2x + 3)\,\textcolor[HTML]{3366CC}{\cdot\;3x} \;+\; (2x + 3)\,\textcolor[HTML]{cc3333}{\cdot\;(-5)} \\[6pt] &= \big(\textcolor[HTML]{3366CC}{6x^2 + 9x}\big) \;+\; \big(\textcolor[HTML]{cc3333}{-10x - 15}\big) \\[6pt] &= 6x^2 - x - 15 \end{aligned} \]

This works, but we already had to distribute twice. As the polynomials get bigger, the number of partial products grows quickly, and it’s easy to lose track.

Imagine distributing for this one:

\[(x + 4)(x^2 - 3x + 2)\]

You would need to distribute \(x\) across three terms, then \(4\) across those same three terms, and then collect all six partial products. The more terms we have, the messier it gets.

Let’s learn a better way to organize everything.

\[x^2 - 3x - 10\]

5.3.2 - Area Models (The Box Method)

Before we use area models for polynomials, let’s remind ourselves how the idea works with numbers.

To multiply \(28 \cdot 47\), you can break each number into place-value parts:

\(40\) \(7\)
\(20\) \(800\) \(140\)
\(8\) \(320\) \(56\)

Add the pieces:

\[800 + 140 + 320 + 56 = 1316\]

Everything has a place. Nothing gets lost.

Area models work the same way with polynomials, but terms are used instead of place-value.

\(300\) \(50\) \(2\)
\(200\) \(60000\) \(10000\) \(400\)
\(80\) \(24000\) \(4000\) \(160\)
\(3\) \(900\) \(150\) \(6\)

\[60000 + 10000 + 400 + 24000 + 4000 + 160 + 900 + 150 + 6 = 99616\]

Example 2: Multiplying two binomials

Let’s return to the product in the first example.

Multiply \((2x + 3)(3x - 5)\).

To use the area model, we put the terms of one binomial across the top, and the terms for the other down the side.

\(3x\) \(-5\)
\(2x\) \(6x^2\) \(-10x\)
\(3\) \(9x\) \(-15\)

Combine like terms and write in standard form:

\[6x^2 - x - 15\]

Compare this to the method that didn’t use an area model. We created all the same partial products, but the area model is simpler and more organized.

Many Algebra books use a method called FOIL to multiply two binomials. FOIL stands for Firsts, Outsides, Insides, Lasts.

In the last example, \((2x + 3)(3x - 5)\), we would use FOIL like this:

  • Firsts: \(2x \cdot 3x = 6x^2\)
  • Outsides: \(2x \cdot -5 = -10x\)
  • Insides: \(3 \cdot 3x = 9x\)
  • Lasts: \(3 \cdot -5 = -15\)

Then we combine:

\(6x^2 - x - 15\)

FOIL works only for binomials. Area models work for all polynomials, no matter how many terms they have.

\(6x\) \(2\)
\(3x\) \(18x^2\) \(6x\)
\(-1\) \(-6x\) \(-2\)

Combine and write in standard form:

\[18x^2 - 2\]

In the next few examples, we will see that the area model really starts to shine when we have more terms to keep track of.

Example 3: A binomial times a trinomial

Multiply \((2x - 3)(x^2 + x + 4)\).

We do exactly the same thing here that we did in the previous example. Terms from one polynomial go across the top and terms from the second go down the side.

\(x^2\) \(x\) \(4\)
\(2x\) \(2x^3\) \(2x^2\) \(8x\)
\(-3\) \(-3x^2\) \(-3x\) \(-12\)

Combine:

\[2x^3 - x^2 + 5x - 12.\]

Example 4: A trinomial times a trinomial

Multiply \((x^2 + x + 3)(2x^2 - x + 4)\).

\(2x^2\) \(-x\) \(4\)
\(x^2\) \(2x^4\) \(-x^3\) \(4x^2\)
\(x\) \(2x^3\) \(-x^2\) \(4x\)
\(3\) \(6x^2\) \(-3x\) \(12\)

Combine:

\[2x^4 + x^3 + 9x^2 + x + 12.\]

Example 5: A binomial times a polynomial

Multiply \((3x + 1)(x^3 - 4x^2 + x + 5)\).

\(x^3\) \(-4x^2\) \(x\) \(5\)
\(3x\) \(3x^4\) \(-12x^3\) \(3x^2\) \(15x\)
\(1\) \(x^3\) \(-4x^2\) \(x\) \(5\)

Combine:

\[3x^4 - 11x^3 - x^2 + 16x + 5.\]

\(2x^2\) \(-3x\) \(9\)
\(-4x\) \(-8x^3\) \(12x^2\) \(-36x\)
\(-7\) \(-14x^2\) \(21x\) \(-63\)

Combine:

\[-8x^3 - 2x^2 - 15x - 63\]

You can use an area model to multiply a monomial times a polynomial. For example, \(3x(x + 3)\) could be written as

\(x\) \(3\)
\(3x\) \(3x^2\) \(9x\)

giving \(3x^2 + 9x\). This is rarely done because it is just as easy to distribute normally.

5.3.3 - Products of More Than Two Polynomials

Sometimes you’ll multiply expressions like:

\[(x + 2)(x - 5)(2x + 3)\]

You can still use area models, just do it in steps.

Multiply the first two polynomials. Then multiply the result by the third.

This keeps each step manageable, and it’s exactly what we do later when factoring or simplifying complicated expressions.

Example 6: A product of three binomials

Multiply \((x - 3)(2x + 1)(x + 4)\).

Step 1: Multiply the first two.

\((x - 3)(2x + 1)\):

\(2x\) \(1\)
\(x\) \(2x^2\) \(x\)
\(-3\) \(-6x\) \(-3\)

Combine:

\[2x^2 - 5x - 3.\]

Step 2: Now multiply that result by \((x + 4)\).

\((2x^2 - 5x - 3)(x + 4)\):

\(x\) \(4\)
\(2x^2\) \(2x^3\) \(8x^2\)
\(-5x\) \(-5x^2\) \(-20x\)
\(-3\) \(-3x\) \(-12\)

Combine:

\[2x^3 + 3x^2 - 23x - 12.\]

Step 1: Multiply \((x + 1)(x - 2)\).

\(x\) \(-2\)
\(x\) \(x^2\) \(-2x\)
\(1\) \(x\) \(-2\)

Combine:

\[x^2 - x - 2.\]

Step 2: Now multiply that result by \((2x - 3)\).

\(2x\) \(-3\)
\(x^2\) \(2x^3\) \(-3x^2\)
\(-x\) \(-2x^2\) \(3x\)
\(-2\) \(-4x\) \(6\)

Combine:

\[2x^3 - 5x^2 - x + 6.\]
