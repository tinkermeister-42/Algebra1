6.3.1The x-Intercepts of a Quadratic

Unlike a line, a parabola can have 0, 1, or 2 x-intercepts.
These x-values are the roots or zeros of the function. They happen exactly when the output is zero.
EX 1. f(x) = x2 + 2x − 15 has vertex (−1, −16). Predict the number of x-intercepts before graphing.

The vertex is below the x-axis and the parabola opens upward, so it must cross twice.

From the graph, roughly x ≈ −5 and x ≈ 3

Why don't we trust graphing for exact answers? the roots are often not whole numbers, so a graph only gives an estimate

6.3.2Solving by Factoring

A quadratic equation looks like ax2 + bx + c = 0.
Why zero? Because x-intercepts happen when the output is zero.
Zero product property: if a product equals zero, then at least one of the factors must be zero.
EX 2. Solve x2 + 2x − 15 = 0 algebraically. Do your answers match EX 1?
Factor(x + 5)(x − 3) = 0
Set each factor to 0x + 5 = 0  or  x − 3 = 0
Solve eachx = −5 or x = 3 — yes, they match EX 1
EX 3. Solve 2x2 = 3x + 4. Not in standard form yet.
Move everything to one side2x2 − 3x − 4 = 0
Factorit does not factor over the integers — b2 − 4ac = 9 + 32 = 41 is not a perfect square
Solutionsx = 3 ± √414 ≈ 2.35 or −0.85 (quadratic formula, 6.6). Note: as 2x2 = 7x + 4 it would factor as (2x + 1)(x − 4) = 0, giving x = −12, 4
EX 4. Solve 8x2 + 60x + 72 = 0. Take out the GCF first.

GCF = 4. Dividing both sides by it does not change the solutions.

Solutions: x = −6, −32

4(2x2 + 15x + 18) = 0 → (2x + 3)(x + 6) = 0

EX 5. Solve 3x3 = 9x + 6x2. Higher degree, same strategy.

How many solutions did you get? 3

3x3 − 6x2 − 9x = 0 → 3x(x2 − 2x − 3) = 0

3x(x − 3)(x + 1) = 0, so x = 0, 3, −1

EX 6. Solve 3x2 − 7x = 6.

3x2 − 7x − 6 = 0 → (3x + 2)(x − 3) = 0

x = −23, 3

6.3.3How Many Solutions?

EX 7. Solve x2 − 5x + 6 = 0, then sketch.

Solutions: x = 2, 3

The graph crosses the x-axis 2 times.

EX 8. Solve x2 − 6x + 9 = 0, then sketch.

Factors as (x − 3)2 = 0

Both factors give the same solution, so there is only one.

The graph touches the x-axis.

EX 9. Try to solve x2 + 4x + 7 = 0, then sketch.

Are there two numbers that multiply to 7 and add to 4? no

So there are no real solutions.

The graph never touches the x-axis.

6.3 Solving Quadratic Equations by Factoring — Practice

Practice

Conceptual Questions

1. How can you tell that an equation is quadratic? the variable is raised to the 2nd power and no higher

2. Why do we set a quadratic equal to zero before factoring? x-intercepts happen when the output is 0, and the zero product property only works against 0

3. What does it mean if a quadratic has only one real solution? the parabola touches the x-axis at exactly one point — a repeated root

4. If a parabola never touches the x-axis, what does that say about its solutions? it has no real solutions, so no real x-intercept

5. Why does (x − 4)2 = 0 have only one solution even though it is a product? (x−4)(x−4) — both factors give the same solution
