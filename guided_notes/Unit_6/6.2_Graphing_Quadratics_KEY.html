6.2  Graphing Quadratics

Guided Notes - Unit 6: Quadratic Equations & Functions - DHS Algebra 1
Teacher Key - answers in red
Objectives
  • Find the axis of symmetry for a quadratic function
  • Find the vertex of a quadratic in standard form
  • Sketch the graph of a quadratic using its key features
  • Identify positive/negative and increasing/decreasing behavior from the graph

Warm-Up

1. Find the slope and y-intercept of y = 3x − 2. How do you use them to graph?

m = 3, b = −2. Plot (0, −2), then go up 3 and right 1.

2. A line has m = 12 and passes through (4, 1). What is b?

1 = 12(4) + b = 2 + b, so b = −1

3. Find the vertex of y = 2x2 + 4x − 1 if its axis of symmetry is x = −1.

f(−1) = 2 − 4 − 1 = −3, so the vertex is (−1, −3).

6.2.1Graphing With a Table of Values

A line needs only 2 points. A parabola curves and turns, so you need at least 5 points to see its shape.
EX 1. Graph f(x) = x2 − 4x + 1 from a table.
x01234
f(x)1−2−3−21

The lowest point is the vertex.

Drawbacks of the table method
  • You need many points to see the shape.
  • The wrong x-values might make you miss the vertex.
  • Squaring and signs invite arithmetic mistakes.
  • It takes much longer than graphing a line.

6.2.2Graphing Using Key Features

Know these three and you only need 2 extra points:

the vertex

the axis of symmetry

the direction it opens

EX 2. Graph the same function from its features: vertex (2, −3), axis x = 2, opens upward.

Pick x = 3: f(3) = −2, giving ( 3 , −2 ).

Its mirror image across the axis is ( 1 , −2 ).

Why does one point give you two? the parabola is symmetric about its axis

Reading the graph

Before the vertex the graph goes down, so the function is decreasing there.

After the vertex it goes up, so the function is increasing there.

If the graph crosses the x-axis twice, the function is negative between the intercepts and positive outside them.
EX 3. Graph f(x) = 3x2 − 6x + 7, whose vertex is (1, 4).

Axis: x = 1   Opens: upward

Extra point and its reflection:

f(2) = 7, so (2, 7); its reflection is (0, 7).

6.2.3Graphing From Vertex Form

f(x) = a(x − h)2 + k

Vertex: (h, k)

Axis: x = h

Opens up if a > 0

EX 4. Graph f(x) = 2(x − 3)2 − 4.

Vertex (3, −4)   Axis x = 3

Opens upward

Using x = 4: point ( 4 , −2 ), reflection ( 2 , −2 )

EX 5. Graph f(x) = −13(x + 2)2 − 1.

Vertex (−2, −1)   Axis x = −2

Opens downward

Using x = 1: point ( 1 , −4 ), reflection ( −5 , −4 )

Gotcha: careful with those signs
In f(x) = 2(x + 3)2 − 2 the vertex is not (3, −2). It is (−3, −2).
Always flip the sign on h and keep the sign on k.
EX 6. Graph g(x) = (x + 1)2 + 3.

Vertex (−1, 3)   Axis x = −1

Opens upward

6.2.4Axis of Symmetry from Standard Form

Standard form is f(x) = ax2 + bx + c. The axis of symmetry is

x = −b2a

This value is also the x-coordinate of the vertex.
EX 7. Find the axis of symmetry of f(x) = −3x2 + 12x + 5.

a = −3   b = 12  →  x = −122(−3) = 2

EX 8. Find the axis of symmetry of f(x) = 2x2 + 4x − 1.

x = −42(2) = −1

6.2.5Finding the Vertex from Standard Form

Once you know the axis x = h, the vertex is always ( h , f(h) ).
EX 9. Find the vertex of f(x) = x2 − 6x + 10.

Axis: x = 3

Then f(3) = 9 − 18 + 10 = 1

Vertex: (3, 1)

EX 10. Find the vertex of f(x) = 2x2 + 8x − 5.

Axis: x = −82(2) = −2

f(−2) = 8 − 16 − 5 = −13, so the vertex is (−2, −13).

Challenge

13. f(x) = a(x − h)2 + k is always positive, even at its minimum. Write a condition on a and k that guarantees this.

The minimum value is k, reached at x = h.

So it is always positive exactly when a > 0 and k > 0.
