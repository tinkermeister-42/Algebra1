The middle term is twice the number inside, and the constant is its square.

Why we need a new method
x2 + 6x + 5 = 0 factors easily, but x2 + 6x + 2 = 0 does not factor over the integers. Both graphs cross the x-axis twice, so both have solutions. We need a method that works every time.

6.5.1Turning x2 + bx into a Perfect Square

A perfect square trinomial comes from squaring one binomial, used twice. So in the area model the two diagonal terms must be equal - which means the middle term gets split in half.
EX 1. Rewrite x2 + 10x as a perfect square.

Split the middle: 10x = 5x + 5x

But we added that amount, so to keep the value the same we must subtract it back out.

x2 + 10x = (x + 5)2 − 25

6.5.2When a ≠ 1

Completing the square works best when the coefficient of x2 is 1. If it is not, factor it out first.
EX 5. Rewrite 3x2 + 12x.

6.5.3Solving a Quadratic Equation

Once an equation is in the form (x − h)2 = k, you finish with the square root property from Lesson 6.4. Completing the square is how you get it into that form.
EX 7. Finish EX 6: solve (x + 2)2 = 52.

x + 2 = ±√52 = ±√102

x = −2 ± √102 ≈ −0.42 or −3.58

EX 8. Solve x2 + 4x − 1 = 0 by completing the square.
Isolate the x termsx2 + 4x = 1
Add to both sidesx2 + 4x + 4 = 5

Solvex = −2 ± √5

EX 9. Solve (x + 1)2 = −6.

Since −6 < 0, there are no real solutions.

EX 10. Solve x2 − 10x + 16 = 0 by completing the square.

x2 − 10x = −16

x2 − 10x + 25 = 9 → (x − 5)2 = 9

x − 5 = ±3, so x = 8 or 2

6.5 Completing the Square - Practice

Practice

Conceptual Questions

1. What does it mean for a trinomial to be a perfect square? it is what you get from squaring a binomial, so it factors as (x ± p)2

2. Why must the middle term be split into two equal parts? the two diagonal boxes must match for the side lengths to be the same

3. In the area model, what does the missing corner represent? the constant that completes the square, (b/2)2

4. Why do we subtract the number we added? so the value does not change - we add and subtract the same amount

5. Without solving, what can you say about the solutions of (x − h)2 = k when…

k > 0  two real solutions

k = 0  one real solution

k < 0  no real solutions

Challenge

20. A quadratic x2 + bx gets rewritten as (x + k)2 − 16. Find b and explain how you know without expanding.

The amount subtracted is always (b/2)2, so (b/2)2 = 16.

b/2 = ±4, so b = ±8 (and k = ±4 to match).

21. For what value of b does x2 + bx + 9 = 0 have exactly one real solution? Solve by completing the square and explain why your answer makes sense.

x2 + bx = −9 → (x + b2)2 = b24 − 9

One solution needs the right side to be 0: b2 = 36, so b = ±6.

That makes sense - those are exactly the cases where it is already a perfect square, (x ± 3)2.
