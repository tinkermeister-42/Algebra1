x = 7 and x = −7 - two of them.

6.4.1The Square Root Property

Factoring only works when a quadratic factors nicely. But x2 = 7 clearly has answers. It is asking what number squares to 7.

If x2 = k, then x = ±√k

Why the ±? Because both a number and its opposite square to the same value.
EX 1 - 4. Solve each.

x2 = 36  x = ±6

x2 = 11  x = ±√11

x2 = 0  x = 0

x2 = −9  no real solution

Why does x2 = −9 have no real solution? no real number squared gives a negative

6.4.2Equations Like (x − h)2 = k

Treat the whole binomial as a single quantity, take the square root of both sides, then solve for x.
EX 6. Solve (x − 3)2 = 16.
Take the square rootx − 3 = ±4
Case 1x − 3 = 4 → x = 7
Case 2x − 3 = −4 → x = −1
EX 7. Solve (x + 5)2 = 3     EX 8. Solve (x − 2)2 = −4     EX 9. Solve (x + 1)2 = 25

EX 7: x + 5 = ±√3, so x = −5 ± √3

EX 8: no real solutions, a square cannot be −4

EX 9: x + 1 = ±5, so x = 4 or −6

6.4.3Rearranging First

If the squared piece is not alone yet, isolate it first, then apply the square root property.
EX 10. x2 − 20 = 0     EX 11. 3x2 = 48

EX 10: x2 = 20, so x = ±2√5

EX 11: x2 = 16, so x = ±4

EX 12. 2(x − 1)2 − 8 = 0     EX 13. (2x + 3)2 = 25

EX 12: (x−1)2 = 4, so x − 1 = ±2 → x = 3 or −1

EX 13: 2x + 3 = ±5, so x = 1 or −4

EX 14. Solve 4x2 − 100 = 0.

4x2 = 100 → x2 = 25 → x = ±5

Gotcha: do not forget the ±
Wrong: x2 = 9 ⇒ x = 3     Right: x2 = 9 ⇒ x = ±3
The only exception is when k = 0.

6.4.4Simplifying Radicals

√n is in simplest form when the number inside has no perfect-square factors except 1.

√(ab) = √a · √b

To simplify, factor out the largest perfect square.
EX 15. Simplify each radical.

√50 = 5√2

√72 = 6√2

√75 = 5√3

√98 = 7√2

Gotcha: use the largest perfect square
√72 = √(4 · 18) = 2√18  ←  not fully simplified - 18 still has a square factor
Keep going: 2√18 = 2 · 3√2 = 6√2. Starting with 36 would have finished it in one step.
