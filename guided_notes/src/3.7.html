3.7.1What Is a Literal Equation?

A literal equation is an equation made mostly of {{a}}variables{{/a}} - a formula. Solving one means {{a}}isolating{{/a}} one variable in terms of the others, using the same {{a}}inverse operations{{/a}} as always.
EX 1. The area of a rectangle is A = lw. Solve for w.
A = lwthe formula
{{a}}{{f A/l}} = w{{/a}}{{a}}divide both sides by l{{/a}}
{{a}}w = {{f A/l}}{{/a}}{{a}}write the wanted variable first{{/a}}

d = rt → t = {{f d/r}}

3.7.2With Addition or Subtraction

Move whole terms with addition or subtraction {{a}}before{{/a}} you multiply or divide.
EX 4. P = 2l + 2w. Solve for w.
P = 2l + 2wthe formula
{{a}}P − 2l = 2w{{/a}}{{a}}subtract 2l from both sides{{/a}}
{{a}}w = {{f P − 2l/2}}{{/a}}{{a}}divide both sides by 2{{/a}}
EX 5. y = mx + b. Solve for x.
y = mx + bthe equation
{{a}}y − b = mx{{/a}}{{a}}subtract b from both sides{{/a}}
{{a}}x = {{f y − b/m}}{{/a}}{{a}}divide both sides by m{{/a}}

24. The area of a trapezoid is A = {{f 1/2}}(b1 + b2)h. Solve for b1.
{{a}}

2A = (b1 + b2)h  →  {{f 2A/h}} = b1 + b2

b1 = {{f 2A/h}} − b2

{{/a}}
25. Total cost is C = np + f, where n is the number of items, p the price each, and f a fixed setup fee. Solve for p, then explain what happens to p as n grows.
{{a}}

C − f = np  →  p = {{f C − f/n}}

For a fixed total C, p shrinks as n grows - the same money is spread over more items.

{{/a}}
