5.1.1Understanding Powers

The base tells {{a}}what number is being multiplied{{/a}}.

The exponent tells {{a}}how many times to use it as a factor{{/a}}.

In 53, the base is {{a}}5{{/a}}, the exponent is {{a}}3{{/a}}, and the value is {{a}}125{{/a}}.
Two powers with the same base are called {{a}}like bases{{/a}}. That is when these rules apply.

Common mistakes to avoid
  • (−3)2 = {{a}}9{{/a}} but −32 = {{a}}−9{{/a}}. The negative must be {{a}}inside the parentheses{{/a}} to be part of the base.
  • Exponents distribute over multiplication and division, not over addition: (x + y)2 {{a}}≠{{/a}} x2 + y2.
  • a0 = {{a}}1{{/a}}, not 0.
