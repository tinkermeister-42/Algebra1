2.5.1What Is Function Notation?

A function is a machine: put a number in, get exactly {{a}}one{{/a}} number out.

f(x) = 2x + 3

f is the {{a}}function name{{/a}}

x is the {{a}}input{{/a}}

2x + 3 is the {{a}}rule{{/a}}

Gotcha: f(x) is not f times x
Read it as “{{a}}f of x{{/a}}”. It names the {{a}}output{{/a}} when the input is x.

2.5.2Is It a Function?

A relation is any set of input/output pairs. A function is a relation where each input has exactly {{a}}one{{/a}} output.
  • Same input with two {{a}}different{{/a}} outputs → not a function.
  • A repeated input is fine if the output is the {{a}}same{{/a}}.
  • Different inputs {{a}}may{{/a}} share an output. That is allowed.
Gotcha
It is only a problem when the same {{a}}input{{/a}} gives different outputs. It is never a problem when the same {{a}}output{{/a}} comes from different inputs.

2.5.3Evaluating Functions

EX 4. g(x) = 3(x + 4). Find g(2).
{{a}}

g(2) = 3(2 + 4) = 3(6) = 18

{{/a}}
EX 5. h(x) = −2(3x − 1) + 7. Find h(−2). Careful with the negatives.
{{a}}

h(−2) = −2(3(−2) − 1) + 7 = −2(−7) + 7 = 14 + 7 = 21

{{/a}}
EX 6. f(x) = 9 − 3x. Find f(2).
{{a}}

f(2) = 9 − 6 = 3

{{/a}}

2.5.4Simplifying Function Rules

A shorter rule is {{a}}faster{{/a}} to use and gives you fewer chances to make a mistake, especially when you evaluate it many times.
EX 7. p(x) = 4(x − 2) + 3x. Simplify first, then find p(5).

Simplified: p(x) = {{a}}7x − 8{{/a}}

p(5) = {{a}}7(5) − 8 = 27{{/a}}

EX 8. Simplify q(x) = 2(x + 5) + 3x, then find q(3).
{{a}}

q(x) = 2x + 10 + 3x = 5x + 10

q(3) = 15 + 10 = 25

{{/a}}
