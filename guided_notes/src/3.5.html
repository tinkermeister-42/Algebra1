3.5.1Equations With No Solution

Sometimes the variables {{a}}cancel out{{/a}} and you are left with a statement that is {{a}}false{{/a}}. Then no value of the variable can work — the equation has {{a}}no solution{{/a}}.

EX 2. Solve 2(x + 4) = 2x + 7.

Conclusion: {{a}}no solution{{/a}}

{{a}}

2x + 8 = 2x + 7  →  8 = 7, which is false.

{{/a}}
Remember — how to recognize no solution
If you end up with two {{a}}different{{/a}} numbers on either side of the equals sign, there is no solution.

3.5.2Equations With Infinitely Many Solutions

Sometimes the variables cancel and you are left with a statement that is {{a}}true{{/a}}. Then {{a}}every{{/a}} number works.
EX 3. Solve 4(x + 2) = 2(2x + 4).
4(x + 2) = 2(2x + 4)the equation
{{a}}4x + 8 = 4x + 8{{/a}}distribute
{{a}}8 = 8{{/a}}{{a}}subtract 4x from both sides{{/a}}
{{a}}true{{/a}}true or false?

Conclusion: {{a}}infinitely many solutions{{/a}}

EX 4. Solve 5y − 3 + 2y = 7y − 3.

Conclusion: {{a}}infinitely many solutions{{/a}}

{{a}}

7y − 3 = 7y − 3 — true for every y.

{{/a}}

Challenge

24. For what value(s) of k does (k − 2)x = 6 − 2k have (a) one solution, (b) no solution?
{{a}}

(a) Any k ≠ 2: the coefficient k − 2 is not zero, so x = {{f 6 − 2k/k − 2}}.

(b) k = 2: the left side becomes 0x = 0 while the right side is 6 − 4 = 2, so 0 = 2 — no solution.

{{/a}}
