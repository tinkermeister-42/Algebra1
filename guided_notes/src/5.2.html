5.2.1Understanding Polynomials

A polynomial is a sum or difference of {{a}}terms{{/a}}. Each term has a {{a}}coefficient{{/a}}, a {{a}}variable{{/a}}, and a {{a}}whole-number{{/a}} exponent.
A constant like 5 still fits, because we can think of it as {{a}}5x0{{/a}}.
We only allow whole-number exponents so the variable never ends up {{a}}in a denominator{{/a}} or {{a}}under a radical{{/a}}.

Challenge

26. Add (x + a) + (x + b) + (x + c). After combining like terms the result has no x term. What must be true about a, b, and c?
{{a}}

The sum is 3x + (a + b + c).

The x-coefficient is 3 no matter what a, b, c are, so the x term can never disappear - the condition is impossible.

(If instead the constant term is to vanish, then a + b + c = 0.)

{{/a}}
