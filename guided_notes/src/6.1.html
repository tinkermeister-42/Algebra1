6.1.1Identifying Quadratic Functions

A linear function has degree {{a}}1{{/a}}, so its graph never {{a}}curves{{/a}}. A quadratic has degree {{a}}2{{/a}}, and that single change lets the graph curve {{a}}once into a U{{/a}}.
From an equation: check the {{a}}highest exponent{{/a}} of x. If it is {{a}}2{{/a}}, the function is quadratic.

6.1.3Domain and Range

A parabola goes on forever left and right, so the domain is always {{a}}all real numbers{{/a}}, written {{a}}(−∞, ∞){{/a}}.
The range depends on the vertex (h, k):

Opens upward → range is {{a}}[k, ∞){{/a}}

Opens downward → range is {{a}}(−∞, k]{{/a}}
