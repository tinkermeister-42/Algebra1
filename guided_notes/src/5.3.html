Challenge

26. (x + a)(x + b)(x + c) has no x2 term when expanded. What relationship must a, b, and c satisfy?
{{a}}

The expansion is x3 + (a+b+c)x2 + (ab+ac+bc)x + abc.

No x2 term means a + b + c = 0.

{{/a}}
27. (x + p)(x + q)(x + r) has no x term when expanded. What relationship must p, q, and r satisfy?
{{a}}

The x coefficient is pq + pr + qr, so pq + pr + qr = 0.
