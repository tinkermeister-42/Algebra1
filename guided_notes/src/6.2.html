Reading the graph

Before the vertex the graph goes down, so the function is {{a}}decreasing{{/a}} there.

After the vertex it goes up, so the function is {{a}}increasing{{/a}} there.

If the graph crosses the x-axis twice, the function is {{a}}negative{{/a}} between the intercepts and {{a}}positive{{/a}} outside them.

So it is always positive exactly when a > 0 and k > 0.
