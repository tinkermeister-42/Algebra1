Warm-Up

1. Why would we use a quadratic to model a ball thrown in the air?

{{a}}

Gravity makes the height rise and then fall — that path is a parabola.

{{/a}}

2. If a quadratic has two solutions, what might they represent in a real situation?

{{a}}

Two moments when the quantity hits that value — e.g. on the way up and on the way down, or two break-even points.

{{/a}}

3. When would only one of the two solutions make sense?

{{a}}

When the other is negative (time, length or a count cannot be negative) or otherwise impossible in context.

{{/a}}

6.7.1Quadratics as Models

Because parabolas curve, quadratics are useful when something {{a}}rises{{/a}} and then {{a}}falls{{/a}}, or has a {{a}}maximum or minimum{{/a}} value.
EX 1. What does each feature tell you in a real situation?
FeatureWhat it tells usExample
Vertex{{a}}the maximum or minimum value{{/a}}{{a}}the highest point of a ball’s flight{{/a}}
y-intercept{{a}}the starting value, at t = 0{{/a}}{{a}}the height it was launched from{{/a}}
x-intercepts{{a}}when the quantity is zero{{/a}}{{a}}when the ball hits the ground{{/a}}

Opening direction{{a}}whether there is a maximum (opens down) or a minimum (opens up){{/a}}{{a}}thrown objects open downward{{/a}}

6.7.2Projectile Motion

An object under gravity is modeled by h(t) = at2 + bt + c, where t is {{a}}time{{/a}} and h is {{a}}height{{/a}}.
EX 3. A ball is thrown upward from 5 feet: h(t) = −16t2 + 40t + 5.

Part 1 — when does it hit the ground? Set h(t) = {{a}}0{{/a}}, because {{a}}the height is zero at ground level{{/a}}.

Solve with the quadratic formula:

{{a}}

t = {{f −40 ± √1920/−32}}, and √1920 = 8√30 ≈ 43.82

{{/a}}

Two answers: {{a}}t ≈ 2.62 and t ≈ −0.12{{/a}}. We reject the negative one because {{a}}time cannot be negative{{/a}}.

The ball lands after about {{a}}2.62{{/a}} seconds.

Gotcha — interpreting solutions
Quadratics often give two answers. In a real problem you have to decide which one {{a}}makes sense in context{{/a}}. Negative {{a}}times{{/a}}, {{a}}lengths{{/a}}, or {{a}}counts{{/a}} usually do not apply.
EX 4. Same ball — what is its maximum height?

The maximum happens at the {{a}}vertex{{/a}}, so t = {{a}}−{{f b/2a}} = −{{f 40/−32}}{{/a}} = {{a}}1.25{{/a}}

Maximum height = h({{a}}1.25{{/a}}) = {{a}}30{{/a}} feet

EX 5. A ball is thrown from 6 feet with h(t) = −16t2 + 24t + 6. When does it hit the ground?
{{a}}

0 = −16t2 + 24t + 6; disc = 576 + 384 = 960

t = {{f −24 ± √960/−32}}; the positive root is t ≈ 1.72 seconds.

6.7.3Area Problems

EX 6. A rectangular garden is 4 feet longer than it is wide and has area 96 square feet. Find its dimensions.

Let x = {{a}}the width in feet{{/a}}, so the length is {{a}}x + 4{{/a}}.

Equation: {{a}}x(x + 4) = 96{{/a}}  →  standard form: {{a}}x2 + 4x − 96 = 0{{/a}}

Solutions: {{a}}(x + 12)(x − 8) = 0, so x = 8 or −12{{/a}}    We reject {{a}}−12{{/a}} because {{a}}a width cannot be negative{{/a}}.

Width {{a}}8{{/a}} ft, length {{a}}12{{/a}} ft

EX 7. A pool has a 2-foot walkway all the way around. Pool plus walkway is 192 square feet, and the pool is 4 feet longer than it is wide. Find the pool's dimensions.

Let w = pool width, so pool length = {{a}}w + 4{{/a}}.

The walkway adds {{a}}4{{/a}} feet to each dimension, so the outside is {{a}}w + 4{{/a}} by {{a}}w + 8{{/a}}.

Equation: {{a}}(w + 4)(w + 8) = 192 → w2 + 12w − 160 = 0{{/a}}

Pool: {{a}}8{{/a}} ft by {{a}}12{{/a}} ft

6.7.4Revenue and Profit

EX 8. Tickets cost $10 and 80 are sold. Each $1 increase loses 5 sales. Find the price that maximizes revenue.

Let x = {{a}}the number of $1 increases{{/a}}

Price: {{a}}10 + x{{/a}}    Tickets sold: {{a}}80 − 5x{{/a}}

Revenue: R(x) = {{a}}(10 + x)(80 − 5x){{/a}} = {{a}}−5x2 + 30x + 800{{/a}}

Vertex at x = {{a}}3{{/a}}, so the price is {{a}}$13{{/a}}, tickets sold {{a}}65{{/a}}, and maximum revenue {{a}}$845{{/a}}.

EX 9. A food truck sells 60 lunches at $8. Each $1 increase loses 4 sales. Write the revenue equation and find the best price.

Careful: the vertex is not a whole dollar. What do you do then? {{a}}check the whole-dollar prices on either side — here R(3) = R(4) = $528, while the exact vertex $11.50 gives $529{{/a}}

{{a}}

R(x) = (8 + x)(60 − 4x) = −4x2 + 28x + 480

Vertex at x = 3.5, so the best price is $11.50.

{{/a}}

Practice

Level 1 — Understanding the Model

1. Which part of a quadratic gives the maximum or minimum value? {{a}}the vertex{{/a}}

2. What does a solution of h(t) = 0 usually represent in a height problem? {{a}}the moment the object reaches the ground (height 0){{/a}}

3. Why do some quadratic solutions get rejected in real problems? {{a}}negative times, lengths or counts do not make sense in context{{/a}}

Level 2 — Applications

4. A ball is thrown up from the ground with h(t) = −16t2 + 32t. When does it hit the ground?

Answer: {{a}}t = 2 seconds{{/a}}

{{a}}

−16t(t − 2) = 0 → t = 0 or 2

{{/a}}
5. A rectangle has area 40 square feet and its length is 3 feet longer than its width. Find the dimensions.

Answer: {{a}}5 ft by 8 ft{{/a}}

{{a}}

x(x+3) = 40 → (x+8)(x−5) = 0

{{/a}}
6. A firework's height is h(t) = −16t2 + 48t + 10. What is its maximum height?

Answer: {{a}}46 feet, at t = 1.5 s{{/a}}

7. Profit from selling x items is P(x) = −x2 + 20x − 60. How many items maximize profit?

Answer: {{a}}10 items{{/a}}

Level 3 — Challenging

8. A ball is thrown up from a 40-foot cliff: h(t) = −16t2 + 16t + 40. When does it hit the ground?
{{a}}

−16t2 + 16t + 40 = 0; divide by −8: 2t2 − 2t − 5 = 0

t = {{f 1 ± √11/2}}; the positive root is ≈ 2.16 seconds.

{{/a}}
9. A rectangle has perimeter 40 units. If the width is x, show the length must be 20 − x. Then find the x that maximizes area.
{{a}}

2x + 2L = 40, so L = 20 − x.

A = x(20 − x) = −x2 + 20x, with vertex at x = 10.

A 10 × 10 square, area 100 — the largest possible.

{{/a}}
10. A quadratic model has zeros at t = 1 and t = 5. What might those represent in a real situation?
{{a}}

The two times the quantity is zero — for example an object leaving the ground at t = 1 and landing at t = 5.

{{/a}}
