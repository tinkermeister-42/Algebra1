4.5.2Solving by Substitution

Steps
  1. Solve one equation for {{a}}one variable{{/a}}.
  2. {{a}}Substitute{{/a}} that expression into the other equation.
  3. Solve for the remaining variable.
  4. Plug back in to find the other one.
Why is this allowed? Because if two expressions are {{a}}equal{{/a}}, you can replace one with the other.
EX 6. Solve by substitution.
y = x + 2 2x + y = 8

Solution: ( {{a}}2{{/a}} , {{a}}4{{/a}} )

{{a}}

2x + (x + 2) = 8  →  3x = 6

{{/a}}
EX 7. Solve by substitution.
y = 3x − 8 x + y = −24

Solution: ( {{a}}−4{{/a}} , {{a}}−20{{/a}} )

{{a}}

x + (3x − 8) = −24  →  4x = −16

{{/a}}

4.5.3Solving by Elimination

Steps
  1. {{a}}Line up{{/a}} both equations.
  2. Add or subtract so one variable {{a}}cancels{{/a}}.
  3. Solve for the remaining variable.
  4. Substitute back to find the other.
EX 8. Solve by elimination.
2x + y = 10 2x − y = 2

Which variable cancels, and do you add or subtract? {{a}}y cancels — add the two equations{{/a}}

Solution: ( {{a}}3{{/a}} , {{a}}4{{/a}} )

EX 9. Solve by elimination.
x + y = 9 x − y = 3
{{a}}

Adding gives 2x = 12, so x = 6 and y = 3 → (6, 3)

{{/a}}

21. The system
y = mx + 4 y = −2x + b
intersects at (2, 0). Find m and b.
{{a}}

At (2, 0): 0 = 2m + 4 → m = −2, and 0 = −4 + b → b = 4.

Note both equations then read y = −2x + 4 — the lines coincide, so they meet everywhere, not just at (2, 0).
