5.2.1Understanding Polynomials

A polynomial is a sum or difference of terms. Each term has a coefficient, a variable, and a whole-number exponent.
A constant like 5 still fits, because we can think of it as 5x0.
We only allow whole-number exponents so the variable never ends up in a denominator or under a radical.

5.2.2Simplifying Polynomials

The process — always the same four steps
  1. Distribute if there are parentheses.
  2. Apply the exponent rules when needed.
  3. Combine like terms.
  4. Rewrite in standard form.

Challenge

26. Add (x + a) + (x + b) + (x + c). After combining like terms the result has no x term. What must be true about a, b, and c?

The sum is 3x + (a + b + c).

The x-coefficient is 3 no matter what a, b, c are, so the x term can never disappear — the condition is impossible.

(If instead the constant term is to vanish, then a + b + c = 0.)
