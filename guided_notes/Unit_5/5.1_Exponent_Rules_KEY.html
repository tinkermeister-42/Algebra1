5.1.1Understanding Powers

The base tells what number is being multiplied.

The exponent tells how many times to use it as a factor.

In 53, the base is 5, the exponent is 3, and the value is 125.
Two powers with the same base are called like bases. That is when these rules apply.

Rule 1 — Product Rule

EX 1. Expand x3 · x5 to see what is really happening.

(x·x·x) · (x·x·x·x·x) = x8

Rule: am · an = am+n  —  multiply like bases, add the exponents.

Try it: r4 · r3 = r7    x9 · x3 = x12

Rule 2 — Quotient Rule

EX 2. Expand x7x3 and cancel.

Rule: aman = am−n  —  divide like bases, subtract the exponents.

Try it: y8y5 = y3    p9p4 = p5

Rule 3 — Power of a Power

EX 3. Expand (x3)2.

Rule: (am)n = amn  —  multiply the exponents.

Try it: (m2)5 = m10    (x3)2 = x6

Rule 4 — Power of a Product

EX 4. Expand (ab)3.

Rule: (ab)n = anbn  —  the exponent goes to every factor.

Try it: (2x)4 = 16x4    (3y)3 = 27y3

Rule 5 — Power of a Quotient

EX 5. Expand (xy)3.

Rule: (ab)n = anbn

Try it: (x3)2 = x29    (2m5)3 = 8m3125

Rule 6 — Zero Exponent

EX 6. What is anything (except 0) to the zero power?

Rule: a0 = 1  (as long as a ≠ 0)

(5y)0 = 1    (3a4)0 = 1    In this course, 00 = undefined

Rule 7 — Negative Exponent

EX 7. Use the quotient rule on a3a5 two ways.

By canceling: 1a2    By subtracting exponents: a−2

Rule: a−n = 1an  and  1a−n = an

A negative exponent does not make a number negative — it moves the factor to the other side of the fraction bar.

Tip
Move factors with negative exponents to the other side of the fraction bar first, then apply the other rules.

Rule 8 — Fractional Exponents

The denominator of the fraction is the root (the index) and the numerator is the power.
a1/n = n√a    am/n = n√(am)
EX 10. Simplify.

82/3 = 4

163/4 = 8

Write 5√(x2) with a rational exponent: x2/5

Write 13√(y4) with a rational exponent: y−4/3

Common mistakes to avoid
  • (−3)2 = 9 but −32 = −9. The negative must be inside the parentheses to be part of the base.
  • Exponents distribute over multiplication and division, not over addition: (x + y)2 ≠ x2 + y2.
  • a0 = 1, not 0.

5.1.2Combining Rules

A helpful routine
  1. Inside first — simplify inside the parentheses.
  2. Exponents next — handle the outer exponent.
  3. Then multiply / divide — combine like bases.
  4. Finish clean — write everything with positive exponents.

4x6x5 = 4x

EX 12. Simplify (3a2b−3)−2

3−2a−4b6 = b69a4

EX 13. Simplify (x−2y4)3x3y−2

x−6y12x3y−2 = x−9y14 = y14x9
