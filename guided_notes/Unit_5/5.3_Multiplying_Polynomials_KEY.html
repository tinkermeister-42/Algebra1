5.3.1Multiplying with Distribution

EX 1. Multiply (2x + 3)(3x − 5) using distribution only.

(2x + 3) · 3x = 6x2 + 9x    (2x + 3) · (−5) = −10x − 15

Combine: 6x2 − x − 15

How many times did you have to distribute? 2

EX 2. Multiply (x − 5)(x + 2) with distribution.

x2 + 2x − 5x − 10 = x2 − 3x − 10

Why we need something better
For (x + 4)(x2 − 3x + 2) you would collect 6 partial products. The more terms, the easier it is to lose a term.

A shortcut you may have seen: FOIL
Firsts: 2x · 3x = 6x2    Outsides: 2x · (−5) = −10x
Insides: 3 · 3x = 9x    Lasts: 3 · (−5) = −15
FOIL works only for two binomials. Area models work for any polynomial.

Challenge

26. (x + a)(x + b)(x + c) has no x2 term when expanded. What relationship must a, b, and c satisfy?

The expansion is x3 + (a+b+c)x2 + (ab+ac+bc)x + abc.

No x2 term means a + b + c = 0.

27. (x + p)(x + q)(x + r) has no x term when expanded. What relationship must p, q, and r satisfy?

The x coefficient is pq + pr + qr, so pq + pr + qr = 0.
