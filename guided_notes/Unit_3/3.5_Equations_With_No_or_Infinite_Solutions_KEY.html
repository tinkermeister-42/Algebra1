3.5  Equations With No or Infinite Solutions

Guided Notes — Unit 3: Solving Linear Equations — DHS Algebra 1
Teacher Key — answers in red
Objectives
  • Recognize when an equation has no solution

Warm-Up

1. Solve 5x + 2 = 3x − 12

2x = −14, x = −7

2. Taylor solved 10x − 9 = 10x + 3 and ended with −9 = 3. Did she make a mistake?

No mistake — the variables cancel and −9 = 3 is false, so the equation has no solution.

3.5.1Equations With No Solution

Sometimes the variables cancel out and you are left with a statement that is false. Then no value of the variable can work — the equation has no solution.
EX 1. Solve 3x + 5 = 3x − 2.
3x + 5 = 3x − 2the equation
5 = −2subtract 3x from both sides
falsetrue or false?

Conclusion: no solution

EX 2. Solve 2(x + 4) = 2x + 7.

Conclusion: no solution

2x + 8 = 2x + 7  →  8 = 7, which is false.

Remember — how to recognize no solution
If you end up with two different numbers on either side of the equals sign, there is no solution.

3.5.2Equations With Infinitely Many Solutions

Sometimes the variables cancel and you are left with a statement that is true. Then every number works.
EX 3. Solve 4(x + 2) = 2(2x + 4).
4(x + 2) = 2(2x + 4)the equation
4x + 8 = 4x + 8distribute
8 = 8subtract 4x from both sides
truetrue or false?

Conclusion: infinitely many solutions

EX 4. Solve 5y − 3 + 2y = 7y − 3.

Conclusion: infinitely many solutions

7y − 3 = 7y − 3 — true for every y.

3.5.3Telling Without Solving

You can often see the answer before you finish solving.
What the two sides look likeHow many solutions
Different variable terms, different constantsexactly one solution
Same variable term, different constantsno solution
Same variable term, same constantinfinitely many solutions
Shorthand: ∅ means no solution and ℝ means all real numbers.
EX 5. Decide how many solutions, without fully solving.

6x = 42  one solution (x = 7)

3x + 8 = 3x + 1  no solution

7x + 9 = 7x + 9  infinitely many

EX 6. How many solutions does each have?

a.  5x + 2 = 3x + 10  one solution (x = 4)

b.  4y + 7 = 4y − 5  no solution

c.  6n + 9 = 9 + 6n  infinitely many

Challenge

24. For what value(s) of k does (k − 2)x = 6 − 2k have (a) one solution, (b) no solution?

(a) Any k ≠ 2: the coefficient k − 2 is not zero, so x = 6 − 2kk − 2.

(b) k = 2: the left side becomes 0x = 0 while the right side is 6 − 4 = 2, so 0 = 2 — no solution.
