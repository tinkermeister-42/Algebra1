3.3.1Distribution in Equations

When the variable is trapped inside parentheses, you cannot isolate it yet. Distribute first.

a(b + c) = ab + ac

EX 1. Solve 3(x + 4) = 21.
StepWhat I did
3(x + 4) = 21the equation
3x + 12 = 21distribute the 3
3x = 9subtract 12 from both sides
x = 3divide both sides by 3
EX 2. Solve −2(2x − 5) = 6. Keep the negative with the 2.
−2(2x − 5) = 6the equation
−4x + 10 = 6distribute the −2
−4x = −4subtract 10 from both sides
x = 1divide both sides by −4
EX 3. Solve 3(2x + 1) = 15.

6x + 3 = 15  →  6x = 12  →  x = 2

3.3.2Combining Like Terms in Equations

If there are like terms on the same side of the equals sign, combine them into one term before you start isolating the variable.
EX 4. Solve 4x + 7 + 2x = 31.
4x + 7 + 2x = 31the equation
6x + 7 = 31combine like terms
6x = 24subtract 7 from both sides
x = 4divide both sides by 6
EX 5. Solve 2(x + 5) + 3x = 25. Parentheses and like terms.
2(x + 5) + 3x = 25the equation
2x + 10 + 3x = 25distribute
5x + 10 = 25combine like terms
5x = 15subtract 10 from both sides
x = 3divide both sides by 5
EX 6. Solve −3(x − 4) + 2x − 3 = 7. Careful with the signs.
−3(x − 4) + 2x − 3 = 7 the equation
−3x + 12 + 2x − 3 = 7distribute
−x + 9 = 7combine like terms
−x = −2subtract 9 from both sides
x = 2divide both sides by −1
EX 7. Solve 4(x + 2) − 3x + 5 = 18.

4x + 8 − 3x + 5 = 18  →  x + 13 = 18  →  x = 5

3.3.3Word Problems with Multi-Step Equations

EX 8. T-shirts. A club sells shirts for $12 each. Making them costs $60 plus $6 per shirt. Their profit was $84. How many shirts?

Let s = the number of shirts

Profit = money in − money out: 12s − (60 + 6s) = 84

Answer: 24 shirts

6s − 60 = 84  →  6s = 144

EX 9. Geometry. A triangle has perimeter 54 cm with sides 2x + 3, 3x − 2, and x + 5. Find x, then find each side.

Equation: (2x + 3) + (3x − 2) + (x + 5) = 54

x = 8    Sides: 19, 22, 13

EX 10. Car wash. A car wash charges $8 per car. Supplies cost $24 plus $2 per car. They earned $96 in profit. How many cars?

8c − (24 + 2c) = 96  →  6c − 24 = 96

6c = 120, so 20 cars

Word Problems

21. A plumber charges $40 for the service call plus $25 per hour, and brought an assistant who also works at $15 per hour. The bill was $160. How many hours did they work?

Equation: 40 + 25h + 15h = 160

40h = 120, so 3 hours

22. A contractor charges $20 per foot of railing plus a $60 permit fee for a rectangular deck that is 3 feet longer than it is wide. The total was $2420. Find the width.

Equation: 20(4w + 6) + 60 = 2420

Perimeter = 2w + 2(w + 3) = 4w + 6

80w + 180 = 2420  →  80w = 2240, so the width is 28 ft

23. A triangle has perimeter 75 cm with sides 3x + 1, 2(x + 4), and x + 6. Write and solve an equation for x.

Equation: (3x + 1) + 2(x + 4) + (x + 6) = 75

6x + 15 = 75  →  x = 10

Challenge

24. T-shirts cost $12 and hoodies cost $24. The number of hoodies ordered was 3 more than twice the number of T-shirts. The total was $312. How many T-shirts?

Let t = T-shirts, so hoodies = 3 + 2t.

12t + 24(3 + 2t) = 312  →  60t + 72 = 312

60t = 240, so 4 T-shirts

25. Solve 2(x + y) + 3x − 4 = 5y + 6 for x in terms of y.

2x + 2y + 3x − 4 = 5y + 6

5x = 3y + 10, so x = 3y + 105
