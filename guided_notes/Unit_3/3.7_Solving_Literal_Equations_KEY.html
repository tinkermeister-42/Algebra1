3.7  Solving Literal Equations

Guided Notes — Unit 3: Solving Linear Equations — DHS Algebra 1
Teacher Key — answers in red
Objectives
  • Identify and solve literal equations
  • Isolate a variable in a formula
  • Use known formulas (area, distance) to solve for any variable

Warm-Up

1. A = lw gives the area of a rectangle.

If A = 24 and l = 6, what is w? 4

What if the length doubled but the area stayed the same? the width would be halved, to 2

2. What do d = rt, F = ma, and P = 2l + 2w all have in common?

They are all formulas — equations built almost entirely out of variables.

3. To get x by itself in 3x + 5 = 20, what do you do first? How would that work in 3x + a = b?

Subtract 5 first. In 3x + a = b you subtract a the same way, giving x = b − a3.

3.7.1What Is a Literal Equation?

A literal equation is an equation made mostly of variables — a formula. Solving one means isolating one variable in terms of the others, using the same inverse operations as always.
EX 1. The area of a rectangle is A = lw. Solve for w.
A = lwthe formula
Al = wdivide both sides by l
w = Alwrite the wanted variable first
EX 2. d = rt. Solve for t.     EX 3. V = IR. Solve for I.

d = rt → t = dr

V = IR → I = VR

3.7.2With Addition or Subtraction

Move whole terms with addition or subtraction before you multiply or divide.
EX 4. P = 2l + 2w. Solve for w.
P = 2l + 2wthe formula
P − 2l = 2wsubtract 2l from both sides
w = P − 2l2divide both sides by 2
EX 5. y = mx + b. Solve for x.
y = mx + bthe equation
y − b = mxsubtract b from both sides
x = y − bmdivide both sides by m
EX 6. Solve 3a + b = 2c for b.

b = 2c − 3a

3.7.3Multi-Step Literal Equations

EX 7. Solve V = Bh + 12 for h.

V − 12 = Bh  →  h = V − 12B

EX 8. Solve A = 12bh + 3 for b.
A = 12bh + 3the formula
A − 3 = 12bhsubtract 3 from both sides
2(A − 3) = bhmultiply both sides by 2
b = 2(A − 3)hdivide both sides by h
EX 9. C = 59(F − 32). Solve for F.
C = 59(F − 32)the formula
95C = F − 32multiply both sides by 95
F = 95C + 32add 32 to both sides

Where have you seen the answer before? it is the Celsius-to-Fahrenheit formula from 2.5

EX 10. Solve PV = nR(T + 2) for T.

PVnR = T + 2  →  T = PVnR − 2

Challenge

24. The area of a trapezoid is A = 12(b1 + b2)h. Solve for b1.

2A = (b1 + b2)h  →  2Ah = b1 + b2

b1 = 2Ah − b2

25. Total cost is C = np + f, where n is the number of items, p the price each, and f a fixed setup fee. Solve for p, then explain what happens to p as n grows.

C − f = np  →  p = C − fn

For a fixed total C, p shrinks as n grows — the same money is spread over more items.
