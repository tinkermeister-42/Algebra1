Objectives

Warm-Up

1. Simplify 32 + 2 · 4 − 1

9 + 8 − 1 = 16

2. How are 2x + 5 and 5 + 2x different? How are they the same?

Same value for every x. Addition can be done in either order.

3. A student evaluates (−3)2 and gets −9. Correct? Why?

No. (−3)2 = 9. The parentheses square the negative too. −32 is the one that equals −9.

2.2.1What Does It Mean to Evaluate?

To evaluate an expression means to find its value. You substitute (replace) the variable with a number. Then you simplify.
When you see =, think “is”. x = 3 means “x is 3”.
EX 1. Evaluate 4x + 1 when x = 3.

Substitute: 4( 3 ) + 1

Simplify: 4(3) + 1 = 12 + 1 = 13

EX 2. The Great Cookie Caper. How is EX 1 like this story? Write the math that matches each part.your turn

The story: 4x + 1

The unknown thief: x

The thief is Bob: x = 3

Bob stole the cookies: 4x + 1 = 13

EX 3. Evaluate 3 − 2x when x = −4.

3 − 2(−4) = 3 + 8 = 11

Gotcha: negatives
It is easy to lose track of negative signs. Put parentheses in place of the variable before you substitute a number.
EX 4. Evaluate 5x − 2 when x = −3.your turn

5(−3) − 2 = −15 − 2 = −17

2.2.2Using PEMDAS with Substitution

Evaluating is one more step on top of the order of operations. First we substitute. Then we use PEMDAS.
EX 5. Evaluate 2(x + 3)2 when x = 1.

2(1 + 3)2 = 2(4)2 = 2 · 16 = 32

EX 6. The variable is in two places. Evaluate 3(2 − y) + 5(y − 2) when y = −4.

3(2 − (−4)) + 5((−4) − 2)

= 3(6) + 5(−6) = 18 − 30 = −12

EX 7. Evaluate 20(x − 2) + 2x2 when x = 5.your turn

20(5 − 2) + 2(5)2 = 20(3) + 2(25) = 60 + 50 = 110

2.2.3Expressions With More Than One Variable

It works the same way with 2 or more variables. Substitute for each variable. Then simplify.
EX 8. Evaluate 2a − 3b when a = 2 and b = 1.

2(2) − 3(1) = 4 − 3 = 1

EX 9. Evaluate 12x − 3y2 when x = 7 and y = −3. Be careful with the negatives.

12(7) − 3(−3)2 = 84 − 3(9) = 84 − 27 = 57

EX 10. Evaluate 12x2 − 3y when x = 4 and y = 3.your turn

12(4)2 − 3(3) = 12(16) − 9 = 8 − 9 = −1

2.2.4Testing for Equivalence

Equivalent expressions look different but always give the same result. To test, substitute the same value into each expression and compare.
EX 11. Test if 5x − 25 and 5(x − 5) are equivalent. Try x = 9.

5(9) − 25 = 45 − 25 = 20

5(9 − 5) = 5(4) = 20

Conclusion: same result, so this is evidence they are equivalent

EX 12. Test if 3(x − 1) and 3x − 2 are equivalent. Try x = 2.

3(2 − 1) = 3(1) = 3

3(2) − 2 = 6 − 2 = 4

Conclusion: 3 and 4 are different, so they are not equivalent

Gotcha: what does this prove?
Different results for the same substitution: the expressions are not equivalent.
Same result: this is evidence that they are equivalent. It does not prove they are always the same.
EX 13. Test if 6y and 2y are equivalent. Try y = 0. Then try y = 3.

y = 0:  6(0) = 0   2(0) = 0      y = 3:  6(3) = 18   2(3) = 6

Conclusion: not equivalent (18 and 6 are different)

EX 14. Test if 9y − 3 is equivalent to 3(3y − 2) + 3 using y = 2. Did you get the same result? What does it tell you?your turn

9(2) − 3 = 18 − 3 = 15

3(3(2) − 2) + 3 = 3(4) + 3 = 15

This tells me: evidence they are equivalent, but we do not know for certain

Summary
evaluateevidenceisnotparenthesesproofsimplifysubstitute

1. To evaluate an expression means to find its value.

2. When you see =, think “is”.

3. In 3 − 2x with x = −4, write −4 in parentheses: 3 − 2(−4).

4. At x = 2, 3(x − 1) is 3 and 3x − 2 is 4. They are not equivalent.

5. At x = 9, 5x − 25 and 5(x − 5) both give 20. This is evidence that they are equivalent.
