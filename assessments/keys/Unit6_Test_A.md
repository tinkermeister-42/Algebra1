1. Opens **up** and the vertex is a **minimum**, because $a = 2$ is positive.
2. Domain: all real numbers. Range: $y \ge -4$.
3. Axis of symmetry $x = 3$; vertex $(3, -4)$.
4. Vertex $(1, -4)$; $x$-intercepts $(-1, 0)$ and $(3, 0)$; $y$-intercept $(0, -3)$. Opens up.
5. $(x + 2)(x + 3) = 0$, so $x = -2$ and $x = -3$.
6. $(x - 5)(x + 1) = 0$, so the $x$-intercepts are $(5, 0)$ and $(-1, 0)$.
7. $x = \pm 7$ &mdash; both roots, not just the positive one.
8. $x - 3 = \pm 4$, so $x = 7$ and $x = -1$.
9. Add $16$: $x^2 + 8x + 16 = (x + 4)^2$. (Half of $8$ is $4$; $4^2 = 16$.)
10. $x^2 + 6x = 7 \Rightarrow (x + 3)^2 = 16 \Rightarrow x + 3 = \pm 4$, so $x = 1$ and $x = -7$.
11. $x = \dfrac{-5 \pm \sqrt{25 + 24}}{4} = \dfrac{-5 \pm 7}{4}$, so $x = \tfrac{1}{2}$ and $x = -3$.
12. $b^2 - 4ac = 16 - 28 = -12$. Negative, so there are **no real solutions**.
13. $w(w + 3) = 40 \Rightarrow w^2 + 3w - 40 = 0 \Rightarrow (w + 8)(w - 5) = 0$. Width $5$ ft, length $8$ ft. (The root $-8$ is rejected: a width cannot be negative.)
14. Vertex at $t = -\dfrac{32}{2(-16)} = 1$ second, and $h(1) = 20$ feet.
