5.1 - Exponent Rules

1. I can apply the rules of exponents to simplify expressions with like bases

  1. x3⋅x7=x^3 \cdot x^7 = ______

    x10x^{10}

  2. a6⋅a=a^6 \cdot a = ______

    a7a^7

  3. (y2)5=(y^2)^5 = ______

    y10y^{10}

  4. (m4)4=(m^4)^4 = ______

    m16m^{16}

  5. n9n2=\dfrac{n^9}{n^2} = ______

    n7n^7

  6. p12p8=\dfrac{p^{12}}{p^8} = ______

    p4p^4

  7. x2⋅x3⋅x4=x^2 \cdot x^3 \cdot x^4 = ______

    x9x^9

  8. (b3)4b5=\dfrac{(b^3)^4}{b^5} = ______

    b7b^7 (the top is b12b^{12}, then subtract 55)

2. I can simplify expressions with zero or negative exponents

Write each answer with positive exponents only.

  1. 60=6^0 = ______

    11

  2. (4x)0=(4x)^0 = ______

    11 (the whole thing is raised to the zero power)

  3. x−2=x^{-2} = ______

    1x2\dfrac{1}{x^2}

  4. 3y−4=3y^{-4} = ______

    3y4\dfrac{3}{y^4} (only yy has the negative exponent, so the 33 stays on top)

  5. 1a−3=\dfrac{1}{a^{-3}} = ______

    a3a^3

  6. 8m2m6=\dfrac{8m^2}{m^6} = ______

    8m4\dfrac{8}{m^4}

  7. c4c9=\dfrac{c^4}{c^9} = ______

    1c5\dfrac{1}{c^5}

  8. (2z)−1=(2z)^{-1} = ______

    12z\dfrac{1}{2z}

5.2 - Simplifying Polynomials

3. I can name a polynomial by its degree and number of terms

  1. 7x−27x - 2 ________________

    linear binomial

  2. x2+5x+6x^2 + 5x + 6 ________________

    quadratic trinomial

  3. −4x3-4x^3 ________________

    cubic monomial

  4. 2x4−x22x^4 - x^2 ________________

    quartic binomial

  5. x3+2x2−x+8x^3 + 2x^2 - x + 8 ________________

    cubic polynomial with 44 term

4. I can write a polynomial in standard form

  1. 4−x24 - x^2 ________________

    −x2+4-x^2 + 4

  2. 2x+5x3−12x + 5x^3 - 1 ________________

    5x3+2x−15x^3 + 2x - 1

  3. 9−2x+x29 - 2x + x^2 ________________

    x2−2x+9x^2 - 2x + 9

  4. x−x4+3x2x - x^4 + 3x^2 ________________

    −x4+3x2+x-x^4 + 3x^2 + x

  5. −5+6x3-5 + 6x^3 ________________

    6x3−56x^3 - 5

5. I can simplify a polynomial by distributing and combining like terms

  1. 6(x2+3x)−2(x2−4x)6(x^2 + 3x) - 2(x^2 - 4x) ________________

    4x2+26x4x^2 + 26x

  2. 3(2y−7)+5(y+3)3(2y - 7) + 5(y + 3) ________________

    11y−611y - 6

  3. 2(5x2−x)−4(x2+2x)2(5x^2 - x) - 4(x^2 + 2x) ________________

    6x2−10x6x^2 - 10x

  4. 6(y+2)−3(2y−5)6(y + 2) - 3(2y - 5) ________________

    2727 (the yy terms cancel, leaving only a constant)

5.3 - Multiplying Polynomials

6. I can multiply two polynomials using distribution

  1. (x+2)(x+8)(x + 2)(x + 8) ________________

    x2+10x+16x^2 + 10x + 16

  2. (x−3)(x+9)(x - 3)(x + 9) ________________

    x2+6x−27x^2 + 6x - 27

  3. (x−5)(x−4)(x - 5)(x - 4) ________________

    x2−9x+20x^2 - 9x + 20

  4. (x+6)(x−6)(x + 6)(x - 6) ________________

    x2−36x^2 - 36 (a difference of squares, so the middle term is gone)

7. I can multiply a binomial by a trinomial

  1. (x+3)(x2+x−4)(x + 3)(x^2 + x - 4)

    x3+4x2−x−12x^3 + 4x^2 - x - 12

  2. (x−1)(x2−2x+6)(x - 1)(x^2 - 2x + 6)

    x3−3x2+8x−6x^3 - 3x^2 + 8x - 6
