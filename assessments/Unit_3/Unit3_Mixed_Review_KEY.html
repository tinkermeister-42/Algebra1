  1. Solve for rr.

    3(r−4)=−2(r+1) 3(r - 4) = -2(r + 1)

    r=2r = 2

  4. Solve for aa.

    5a−2(a−1)=3a−2 5a - 2(a - 1) = 3a - 2

    No solution. The left side simplifies to 3a+23a + 2, leaving 2=−22 = -2, which is never true.

  5. Gym A charges $30\$30 to join and $15\$15 each month. Gym B charges $10\$10 to join and $20\$20 each month. Write and solve an equation to find the number of months when the two gyms cost the same.

    30+15m=10+20m30 + 15m = 10 + 20m, so m=4m = 4. After 4 months, both gyms cost $90\$90.

  6. The area of a trapezoid is A=12(b1+b2)hA = \dfrac{1}{2}(b_1 + b_2)h. Which equation shows this formula solved for b2b_2? Circle the correct answer.

    d. b2=2Ah−b1b_2 = \dfrac{2A}{h} - b_1

    1. b2=2A−b1hb_2 = \dfrac{2A - b_1}{h}
    2. b2=2Ah−b1b_2 = 2Ah - b_1
    3. b2=A2h−b1b_2 = \dfrac{A}{2h} - b_1
    4. b2=2Ah−b1b_2 = \dfrac{2A}{h} - b_1

  7. You have $40\$40. You buy a pizza for $13\$13. Drinks cost $3\$3 each. Write and solve an inequality to find how many drinks you can buy.

    13+3d≤4013 + 3d \le 40, so d≤9d \le 9. You can buy at most 9 drinks.

  8. Sam and Ana both solved 3x−2y=123x - 2y = 12 for yy.
